# 基金综合评估（多子代理编排）

主代理**不亲自算四维**。它负责：定目标 → 备数据 → 一次性并发出四个子代理（各自算、各写一份 temp 文件、各回一句话）→ 读回四份文件，按模板整合成最终报告。四个子代理互不可见、互不改文件。

## 约定（先读）

- `<skill_dir>` = 本 SKILL.md 所在目录（含 `scripts/`、`assets/`）。运行时在**当前会话工作目录**下建 `temp/` 与 `output/`，不写进 skill 目录。
- 数据文件统一放 `temp/_inputs/`。子代理是全新上下文，**不继承本 skill**——给它们的任务描述必须自包含（路径写绝对、命令写全、口径写清）。
- Python 依次试 `python`、`py -3`。子代理与其脚本都不需要联网（数学在本地算）；只有主代理第 0 步联网取数。
- 本评估是研究/演示产物，非投资建议；合规维度命中项标"待人工"，不定论。

## 第 0 步：定目标 + 备数据（混合策略）

先定 `fund_id`（6 位基金代码；没有就给名称拼音缩写）。然后**先试 akshare 自动拉**，拉不到再向用户要文件：

```bash
python "<skill_dir>/scripts/fetch_fund.py" --fund {fund_id} [--bench 000300]
```

**做（Why：数据决定子代理能算多真。东财接口本机常被拒，拉不到是常态，不是失败）：**
- 净值/基准拉到即落 `temp/_inputs/nav.csv`、`bench.csv`。持仓与合规要的"定期报告前十大/关联名单"基本得用户给文件，一次问清。
- 拉不到净值时 **fetch 脚本会友好退出**，此时向用户要 `nav.csv`（列 `date,nav`）；别拿指数/现价糊弄成净值。
- 需要材料一次列清单：业绩要净值；风险要净值+基准（可选）；持仓要最新季报前十大（可选上期）；合规要前十大+可选 meta。全都放 `temp/_inputs/`，列名按各 dim 脚本 docstring。

## 第 1 步：校验输入

- 至少 `nav.csv`（或等价的净值序列）存在，否则停下等用户补。
- 每个维度**缺数据就让它在该维文件里写明"缺什么、待补后能算什么"**，不许凭空造数。缺得多的维度照样派子代理，它负责如实降级。

## 第 2 步：一次并发出四个子代理

**在同一个回合里把四个 Agent 全部发出去**（分开发=串行=慢）。每个子代理一个任务，只做自己那维：

| # | 子代理 | 跑脚本 | 写文件 | 需要输入 |
| --- | --- | --- | --- | --- |
| 1 | 业绩 | `dim_performance.py --fund {id} --nav …/nav.csv [--peers DIR]` | `temp/performance_{id}.md` | nav.csv |
| 2 | 持仓 | `dim_holdings.py --latest …/holdings_latest.csv [--prev …]` | `temp/holdings_{id}.md` | 持仓报告 |
| 3 | 风险 | `dim_risk.py --nav …/nav.csv [--bench …/bench.csv]` | `temp/risk_{id}.md` | nav.csv(+bench) |
| 4 | 合规 | `dim_compliance.py --latest … [--meta …]` | `temp/compliance_{id}.md` | 持仓报告 |

给每个子代理的提示词**统一骨架**（自己补齐具体路径）：

> 你是基金综合评估的「{维度}」子代理，对象 {fund_id}。数据在 {temp/_inputs 绝对路径}。
> ① 用命令跑脚本：`python "<skill_dir 绝对路径>/scripts/{dim}.py" {参数}`，把数值写进脚本指定的 md。
> ② 脚本只出数字；你再在 md 末尾追加 `## {维度} 观察`，写 2–4 行人话解读（有什么值得注意/口径疑点）。
> ③ 只改你自己的 `{输出文件}`，不要动其他文件。完成后**只回一句话摘要**（数字要点即可），别回长文。

**做（Why：多代理的价值=并行+专职，但交接必须可靠）：**
- 子代理的**最终交付物是文件**，不是返回文本（返回会被截断）。主代理绝不靠它们的回复文字攒报告。
- 四个都回来后，先确认四个文件都在且非空——**哪个缺失就补派哪个**，别默默跳过一维。
- 合规子代理的"双十/关联/禁投"是**披露口径代理检查 + 字符串初筛**，命中只标"待人工"，与 investment-compliance 的证据式口径一致，不重复造规则。

## 第 3 步：整合（主代理亲自做）

1. 读 `assets/fund_eval_template.md` 与四个 temp 文件。
2. 按模板把四维摘要填进去：每节开头放该维子代理的一句话摘要，正文放关键表/观察。
3. 综合结论要能**指回出处**（"持仓集中度 41%，见持仓节"），别写无来源的感受。
4. 写 `output/fund_eval_{fund_id}_{date}.md`，目录不存在先建；再在对话里给一段要点摘要。

## 收尾自查

- 四个 temp 文件都在 `temp/`、非空；缺哪个补派过哪个。
- 报告每节有子代理一句话摘要 + 可溯源数字；没把"缺数据/降级"说成"算好了"。
- 合规命中项标"待人工"；报告落 `output/fund_eval_{fund_id}_{date}.md`。
- 明确告知用户：数据来自自动拉取还是用户文件、缺了什么可补。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 东财拉不到净值 | 正常降级：问用户要 nav.csv；fetch 已给友好提示，不伪造 |
| 某个子代理文件没生成 | 单独补派那个维度，不重跑其它三个 |
| 没有同类基金池 | 业绩维不硬排同类，写明 N/A；可对比基准替代 |
| 持仓只披露前十大 | 集中度/合规按代理口径算，并在文件里标注可能低估 |
| 用户只要一个维度 | 那就只派那个子代理，不硬凑四份 |
| 报告某节数字存疑 | 追到对应 temp 文件/脚本口径；脚本有 assumption 段落 |
