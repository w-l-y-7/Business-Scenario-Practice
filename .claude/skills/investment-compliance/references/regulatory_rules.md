# 合规检查规则清单（境内为主 + 国际制裁外挂）

> 供 SKILL.md 步骤 2 逐项核对用。阈值为公开规则**摘编与示例默认值**，执行时以**现行有效法规**及**本机构合规手册**为准；标注【示例】的为草稿默认、需机构确认。逐条给"依据"是为了让你能追溯，不是替代原文。

## A. 制裁与黑名单筛查（证据式）

| 名单/来源 | 要点 |
| --- | --- |
| OFAC SDN List（美国） | 主体命中即受限；同名/相近拼写需人工比对（拼音/曾用名/别名） |
| EU 金融制裁综合名单 | 欧盟共同外交与安全政策项下资产冻结名单 |
| UN 安理会制裁名单 | 与资产冻结/武器禁运相关主体 |
| 境内反洗钱黑名单 | 人民银行/反洗钱监测、外汇局违规企业名单 |
| 境内市场禁入/自律 | 证监会市场禁入者、交易所/协会公开谴责与限制名单（A股语境） |

**判定口径（强约束）：**
- "未命中"必须**有权威来源核对证据**（官方查询结果/单号、行方或合规系统留痕），否则判**待复核**。
- 证据来源不权威或过期 → 降级待复核。
- 本技能**不内置名单快照**，不承担"本地名单=已核对"的假象。

## B. 投资集中度

| 检查项 | 依据 | 判定示例 |
| --- | --- | --- |
| 单只基金持有单一公司证券 | 公募"双十"：市值 ≤ 基金净值的 10% | 单一标的市值 / 基金净值 > 10% → 超限 |
| 同一管理人全部基金持有单一公司证券 | 双十第二条：全部持有 ≤ 该证券的 10% | 需管理人全产品口径数据，缺则待补 |
| 单一标的敞口占净值（机构内规常见档） | 机构合规手册【示例】 | ≤10% 通过；10–20% 关注/待复核；>20% 不通过 |
| 单一对手方敞口集中度 | 机构内规/流动性要求【示例】 | 超机构设定上限 → 不通过 |

- 判定需要：该笔金额 + 当前组合净值（或该标的全部持仓）。**缺净值 → 该项标"待补数据"，不得默认不超限。**

## C. 关联交易识别

- 关联方常见口径（以适用上市规则/机构制度为准）：控股股东、实际控制人、董监高及其直接或间接控制/施加重大影响的法人或自然人、同一控制下的其他主体、近亲属等。
- 判定流程：
  1. 对手方名称与关联方清单**精确比对**；
  2. 不在清单、但名称/股权结构/历史关系存疑 → 判"**疑似关联，待人工确认**"；
  3. 疑似关联 → 是否需回避、按公允价、走审批、履行披露，交给合规/审批流程，不由本技能拍板。

## D. 其它必查（按资产类别与方向）

| 场景 | 检查点 |
| --- | --- |
| A股个股 | 是否限售/锁定期/窗口期（如董监高敏感期）；是否 ST/*ST、退市整理、禁投行业（按产品合同） |
| 公募/资管产品 | 投资范围与比例限制是否与合同一致；被动超限的补救时限 |
| 衍生品/杠杆 | 保证金与杠杆比例上限；交易权限 |
| 私募/合格投资者 | 投资者适当性门槛与人数限制；宣传合规 |
| 跨境 | 资金跨境合规、外汇额度；与 A 叠加 |

命中即单独记录；多数状态（限售解禁、ST 与否）需**人工核到最新**，不得凭记忆。

## E. 证据与免责边界

- 报告里每条"通过/未命中"背后须有**可引用证据**（来源+时间+单号/留痕）。无证据 = 待复核。
- 本清单辅助人工合规判断；输出报告供合规岗签核，**不替代机构最终放行决策**。
- 规则文本与阈值会变：动手前先对照当前版本法规/手册，冲突时以最新官方文本为准。
