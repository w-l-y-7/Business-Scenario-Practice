# 跨数据源综合研究（学术文献 × 市场数据）

把「主题深度研究」编排成一条确定性流水线：**第 1 步从学术文献提取学界共识，第 2 步用市场数据刻画行情，第 3 步把两边交叉验证成一份研究报告**。每一步都要落成一个产物文件，下一步只消费上一步的产物——不要跳步，更不要在第 3 步现编第 1、2 步的数据。

## 约定（先读）

- `<skill_dir>` = 本 SKILL.md 所在目录。运行时产物一律放**当前会话工作目录**下的 `output/`，不要写进 skill 目录。
- 文件名以 `{topic}_{YYYY-MM-DD}` 命名：`{topic}` 用斜杠/空格等不安全字符替换成 `_`（中文保留）；日期默认**今天**（运行日），也接受用户给定的"数据截至日"。例：`output/literature_summary_ai算力_2026-09-07.md`。
- 每份文件在**报告开头自带数据源/口径标注行**（哪个 server、哪只标的/指标、截至日、单位），后续引用一律溯源到它。
- 依赖两个外部 MCP 服务器，**预期命名**（照着配即可直接生效）：
  - server `scholar`，工具 `search` → `mcp__scholar__search`：学术文献检索。
  - server `market`，工具 `query`（行情/时间序列）与 `indicators`（派生指标）→ `mcp__market__query`、`mcp__market__indicators`。
- 若工具名对不上、服务器没装，先看**第 0 步**的映射与兜底，**绝不用编造的调用凑**。

---

## 第 0 步：解析任务 & 核对数据源能力

1. 从用户的话里提取 **{主题 topic}** 与 **{市场口径 scope}**。口径没给清楚时（例如只说了"AI 算力"）→ **向用户确认**：看哪个市场（A股 / 美股 / 全球？）、用哪条指数或资产作行情代理，别自己替他定。
2. **核对可用工具**：浏览当前会话可用工具里所有 `mcp__*`，把三类能力映射到实际工具名——
   | 能力 | 预期工具（照着配） | 兜底：按意图映射 |
   | --- | --- | --- |
   | 学术检索 | `mcp__scholar__search` | 任意能返回论文/文献列表的 `mcp__*` |
   | 行情数据 | `mcp__market__query` | 任意能取价/时间序列的 `mcp__*` |
   | 指标数据 | `mcp__market__indicators` | 同 server 的指标类工具 |
3. **能力缺失时停下来**：若三类能力任一没有对应工具，先检查是"没装 server"还是"改名了"。没装 → 告诉用户按上面预期命名接入（可用 `/mcp`）；改名 → 用兜底映射继续并在错误备注里记一笔。**发现没有任何可用数据源时，直接告诉用户需要先配置 MCP，不要空跑。**
4. 把 `topic`、`scope`、实际工具名、映射/缺失情况写进一段**错误备注**，随三个阶段带入报告。

## 第 1 步：学术文献检索（Scholar MCP）

产物：`output/literature_summary_{topic}_{date}.md`

1. 调学术检索工具，**默认近 3 年**窗口（用户可改）；关键词从 topic 拆 1~2 个角度，检索词不够就扩写同义/上位词。
2. 挑 8~15 篇**相关度最高**的：先看题名与摘要过滤掉纯标题党的，优先近两年 + 高被引/知名期刊会议。
3. 每篇只提炼一行「方法 + 核心发现」，不整段抄摘要。

**做（Why：文献综述是后面「一致性/分歧」判断的一方证据，质量决定报告可信度）：**
- 把文献间的**共识与分歧**单列出来：哪些结论被多篇互相印证，哪些是单篇孤证。单篇结论要说清是"个案"不是"定论"。
- 区分论文讲的是**事实性发现**（如某模型效果提升）还是**判断性观点**（如某技术路线会胜出），整合阶段处理方式不同。
- 检索为空 → 放宽年份 / 换更宽关键词重试一次；仍空就照实写"该窗口无检索结果"，别硬凑。

## 第 2 步：市场数据获取（Market MCP）

产物：`output/market_analysis_{topic}_{date}.md`

1. 按第 0 步确定的 scope，调行情工具取**代理标的**的价格/指数时间序列，调指标工具取**能反映该主题景气度的派生指标**（如板块指数、成交量、估值分位等，以实际可得的为准）。
2. 窗口默认取**近 1 年与近 3 年**两档（用户可改），用于看短中两个趋势。

**做（Why：市场数据是"市场视角"，要能和文献的时间尺度对上，取数口径错一步整个对比就没意义）：**
- 算趋势时写清楚口径：区间涨跌幅、同比、是否复权、单位、数据截至日。
- 找出**关键转折点**：窗口内的阶段高/低点与大致时间，标注时点附近的**事件候选**（如某政策/新品），但只做"可能相关"的提示，不宣称因果。
- 数据是截至日快照还是当日实时，写明白。遇到停牌/非交易日等缺数，在文件里标注缺了哪一段。
- sanity check：涨跌幅出现离谱值（如 ±1000%）要复核口径，多半是除权或单位错。

## 第 3 步：报告整合

产物：`output/research_{topic}_{date}.md`

1. 读取前两步的产物，按下面模板成文；模板内的数字**只准引用前两步文件里出现的**，不许改数、不许现编。
2. 一致性判断：学术共识 vs 市场走势同向 → 写"印证/一致"；反向 → 写"分歧"。**分歧只给假设不给断言**：可能是市场在定价未来预期、可能是学术结论滞后、可能是两边时间尺度/口径不同——列出候选解释并说明无法在此数据集内判定。
3. 任一步数据缺失（server 挂了 / 检索为空 / 指标取不到），**照常完成报告**，把缺口写进"缺失与局限"小节。

**报告模板（固定结构，可加二级小节但别改顺序）：**
```markdown
# {主题} · 跨数据源综合研究（{YYYY-MM-DD}）

## 1. 摘要
两句话：学界总体怎么看 + 市场总体怎么走 + 二者是否一致。

## 2. 文献综述（学界视角）
- 核心问题与检索口径（检索词、年份窗口）
- 主要发现：逐条 + 出处（作者/年份）
- 学界共识 / 学界分歧（标清哪些是孤证）
- 方法趋势与开放问题

## 3. 市场数据分析（市场视角）
- 数据快照：代理标的、指标、截至日、单位
- 短/中期趋势与转折点
- 与主题直接相关的关键指标解读

## 4. 一致性 / 分歧
- 一致处：学术发现 ↔ 市场表现的对应点
- 分歧处：列出候选假设（不断言因果）

## 5. 综合判断与局限
- 站在「学界 × 市场」两个视角的收敛结论
- 明确写出本报告的局限（数据缺口、口径不匹配、孤证等）

## 6. 来源与缺失标注
- 每个数据点溯源：文献给作者/年份，行情给标的+server
- 错误备注：哪些数据源失败 / 哪些部分缺失
```

## 错误处理（贯穿全程）

| 情况 | 处理 |
| --- | --- |
| 某 MCP 连接失败 / 工具不存在 | 记入错误备注，用已成功的数据源把报告写完，缺的部分在第 6 节如实标注 |
| 没有任何可用数据源 | 停下，让用户先配置 MCP（按上文预期命名），不产出空报告 |
| 检索无结果 | 放宽年份/换词重试一次；仍无则如实写空，不编文献 |
| 数据不完整 / 有缺段 | 正常写，缺口在"缺失与局限"标注 |
| 指标与该主题对不上 | 问用户换哪个代理指标，不硬套 |
| 仅剩单边数据（只有文献或只有行情） | 第 4 节标注"缺另一边，无法交叉验证" |

## 收尾自查

- 三份产物齐全且命名正确：`literature_summary_*`、`market_analysis_*`、`research_*`。
- 报告每个数字都能溯回中间产物；没有编造的文献、价格或指标。
- 第 4 节分歧写的是假设，没有把相关性说成因果。
- 失败/缺失的数据源都在第 6 节如实标注。
- 中间产物与报告开头都有数据源/口径/日期标注行。
