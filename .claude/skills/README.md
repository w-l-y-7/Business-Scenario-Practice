## 先搞清楚一件事

这些文件是**写给 Claude 读的操作指令**，不是给你背的。你不需要记住它们。

- **正常用法**：用自己的话把需求说清楚就行，Claude 会自己去挑用哪个技能。比如「帮我算一下这个基金组合的夏普比率」，它自己就会去找相关的技能。
- **想点名**：也可以直接打 `/技能名`，例如 `/brainstorming`、`/systematic-debugging`。

它们原本是为**软件工程师写代码**设计的。你做金融科技课题，用得上的是里面那套「想清楚 → 拆计划 → 验算 → 出错找根因」的方法，用不上的是跟代码分支管理有关的那几个。

## 另一半：6 个金融领域技能

上面那 15 个是**流程技能** —— 教「怎么做事」的方法论，本身不产出金融内容。

下面这 6 个是**领域技能** —— 真的去做金融分析的，自带 Python 脚本、模板和规则文件。它们是 2026-09-17 从另一个实验仓库并进来的。

| 技能 | 干什么 | 什么时候找它 |
| --- | --- | --- |
| **quarterly-financial-analysis** | 对一家 A 股上市公司做财报分析：联网抓三大报表 → 算核心比率 → 对照行业基准 → 出结构化报告。自带行业基准表（申万一级、按公开年报自算中位数） | 问「XX 公司财报怎么样」「算一下它的 ROE 和毛利率」「跟同行业比比」 |
| **smart-data-analysis** | 分析任意数据文件（CSV / Excel / 数据库）。按数据规模自动选路：小文件本地算，大文件或多表关联进 sqlite，要实时行情走 akshare | 问「帮我看看这个 csv」「把这两张表关联起来统计」「某股现价和近期走势」 |
| **fund-comprehensive-evaluation** | 对一只基金做综合评估：业绩 / 持仓 / 风险 / 合规四路并行分析，再整合成一份报告 | 问「这只基金怎么样」「值不值得买」「查查持仓和风险」 |
| **investment-compliance** | 对一笔或一批交易做合规审计：制裁名单核对、投资集中度、关联交易、风险定级。证据不足时判「待复核」，不自动放行 | 问「这笔能不能放行」「集中度超没超限」「出份合规报告」 |
| **policy-brief-generator** | 把政策文件 / 研究报告压成结构化简报。走「模板成稿 → 脚本机械检查 → 最多 3 轮精修 → 事实溯源核对」的闭环 | 问「把这份政策做个简报」「提炼成摘要+背景+分析+建议」 |
| **cross-platform-research** | 跨学术文献 × 市场数据做主题研究，三段流水线产出报告。**依赖两个 MCP 数据源，本机还没配**，要先用得先接入 | 问「学界怎么看、市场怎么走」这类要同时查论文和行情的题目 |

**两组容易混的边界**：

- 「某股**现价 / 走势**」→ `smart-data-analysis`；「某股**财报 / 比率 / 同业对比**」→ `quarterly-financial-analysis`。
- `quarterly-financial-analysis` 是**联网抓数自己算**；`investment-research/` 目录下的 `fundamental`、`earnings-extract` 是**从已有材料里提取和判断**。两边都沾边的说法，先问清楚你要的是补数据还是下判断。

**注意**：这 6 个技能跑起来会在**当前目录**建 `data/`、`temp/`、`output/` 放中间产物。仓库根的 `.gitignore` 已经把它们排除掉，不会被误提交。

## 第一梯队：你大概率真用得上

| 技能 | 干什么 | 对你意味着什么 |
| --- | --- | --- |
| **brainstorming** | 动手前先把你到底要什么问清楚，提出 2-3 个方案让你选 | 写论文、做数据分析、搭一个小工具之前用它。**能省下大量返工** —— 很多人卡住不是不会做，是一开始就没想清楚要做啥 |
| **writing-plans** | 把复杂任务拆成一份分步计划文档 | 课题一复杂就容易乱。用它先把「第一步做什么、第二步做什么」列出来 |
| **systematic-debugging** | 遇到报错或结果不对，先系统性地找根因，别瞎改 | 程序跑不出结果、数字对不上时用它。核心是「先定位原因，再动手改」 |
| **test-driven-development** | 先写检查程序，再写实现 | 金融计算的关键技能。算收益率、估值、手续费这些东西，**先写下「我期望结果是多少」，再让它去算**，能挡住绝大多数算错 |
| **verification-before-completion** | 声称「做完了」之前，必须真的跑一遍验证 | 防止被忽悠。不管是 Claude 说完成了，还是你自己觉得做完了，都先验一遍再下结论 |

## 你可能会有的疑问

**这些技能会自己跳出来打断我吗？**
不会。技能只在相关时才被调用。不过 `using-superpowers` 会要求 Claude 在每个任务开始前先想一下「有没有合适的技能」，所以你会感觉它偶尔会先来问你几个问题 —— 那通常是好事。

**「子代理」「worktree」「分支」这些词还是看不懂怎么办？**
直接问 Claude。你可以说「用大白话解释一下 subagent 是什么」，它会用金融场景给你类比。

**翻译过了，以后还想跟上原作者更新怎么办？**
翻译后这些文件就和英文原版分叉了，直接覆盖会丢中文。原始英文版备份在 `C:\Users\王\AppData\Local\Temp\superpowers-clone`（临时目录，可能被系统清理，要长期保留得另存一份）。
