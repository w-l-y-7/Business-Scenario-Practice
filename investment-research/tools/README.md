# tools/ —— 程序

脚本放这里。目前只有一个组件：

| 目录 | 是什么 |
| --- | --- |
| `model/` | 统一估值模型：九个模块 + 三情景 + 两组敏感性，外加输出门禁 |

用法、口径与三条硬规矩见 [model/README.md](../model/README.md)。

## 约定

- **纯 Python + PyYAML**，不引额外依赖。数据文件用 YAML（可读）与 JSON（结果）。
- 脚本只管算，**不放结论**。判断写在 `analysis/` 的文稿里。
- 缺输入要**报错**，不许静默按 0 算，也不许返回一个「看起来合理」的数。
- 改动脚本后跑一遍自测：`python tools/model/selfcheck.py`。
