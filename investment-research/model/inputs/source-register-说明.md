# 证据登记表使用说明

本文件解释 `model/inputs/source_register.csv`（证据登记表）怎么读、怎么用，并列出本项目**当前还缺哪些材料**。

## 一、这张表是干什么的

`source_register.csv` 是**证据索引**，登记 `raw_data/` 下每一份原始材料的来源与可信度。

- **对模型**：模型输入只能引用表里**存在**、且 `status` **允许**的 `source_id`。引用未登记的 id 或不允许的状态，模型**报错**，不静默算下去。
- **对下游**：`raw_data/` 只读。新材料一律先登记进本表，别处不分析未登记材料。
- **一句话**：登记表是「哪些数能进模型、凭什么能进」的准入台账，不是可选台账。

一轮登记对应一批导入材料。本次登记覆盖 `raw_data/` 四个子目录（`earnings/`、`filings/`、`news/`、`reports/`）与 `market/`，共 **47 行**、**47 个文件**（`.gitkeep` 占位文件不计）。

## 二、每列什么意思

| 列 | 含义 |
| --- | --- |
| `source_id` | 稳定代号，大写 ASCII，一文档一行。前缀：`AR` 年报、`Q1/Q3` 季报、`H1` 半年报、`KPI` 关键指标提取稿、`IR` 投资者关系、`SM` 自媒体、`IDX` 索引、`LNK` 链接记录、`MKT` 行情。 |
| `source_file` | 相对 `investment-research/` 的文件路径，正斜杠，与磁盘上文件名一致。 |
| `title` | 文档自己的标题。 |
| `issuer` | 谁发的（公司 / 交易所 / 监管机构 / 媒体 / 券商）；本项目自制的提取稿、索引、汇总记为「本项目 …」。 |
| `publication_date` | 对外披露日期，`YYYY-MM-DD`。**看不到确切日期就写「待核实」并说明卡在哪，绝不编一个**。区分两种缺失：**待核实**＝没打开原文核对；**未披露**＝查过了、原文确实没写（本项目按 `data-standard.md` §5 要求区分，两者不可互换）。 |
| `page` | 页码。本轮登记的是**整份文档**，非某一数字，故一律「不适用」；单数字的页码见各 `-关键指标.md` 文件内部。 |
| `source_type` | `official_filing` 定期报告 / 交易所公告原件；`regulator` 监管公示；`company_voluntary` 公司自述；`broker_research` 券商研报；`media` 财经媒体；`data_terminal` 数据终端；`social_media` 自媒体；`link_record` 链接 / 索引记录。 |
| `source_tier` | A / B / C / D，评的是来源本身（`data-standard.md` §4.1）。 |
| `assurance_status` | 经审计 / 经审阅 / 经第三方鉴证 / 未经审计 / 不适用 / 无法判断。**年报「已审计」、半年报与季报「未经审计」是常态，必须标出**。 |
| `claim_type` | 事实 / 观点 / 混合 / 不适用。**观点只能当观点引用**。 |
| `retrieval_date` | 拿到材料的日期，不是发布日。本批多为 2026-09-18（财报）、2026-09-20（公告 / 新闻 / 研报），行情与新闻汇总为 2026-09-17。 |
| `status` | 见第三节。 |
| `notes` | 口径、分歧、缺口、待核实说明。含逗号的字段整段加双引号（本表已避免在正文用半角逗号）。 |

### 本次的两个登记约定（非规范，仅本批的处理）

1. **提取稿与汇总稿**（`*关键指标.md`、`行情数据.md`、`近期新闻.md`、`券商研报摘要.md`）登记为 `status = derived`：它们是 PDF 的数**据提取**或媒体**标题概括**，**不是独立来源**，数字须回原件核对。
2. **索引 / 链接记录**（`公告与治理材料索引.md`、`贸易政策材料.md`、`同业公司材料.md`、两个 `网址*.docx`）登记为 `source_type = link_record`、`source_tier = D`：它们是找材料的入口，本身不作证据，仅作查询线索。

## 三、模型接受哪些 status

| status | 能不能进模型 | 含义 |
| --- | --- | --- |
| `reported` | **可** | 原始材料，如实登记，未经复核。 |
| `derived` | **可** | 由原始材料派生的提取稿 / 计算指标，须能回溯到 `source_file`。 |
| `approved` | **可** | 已经人工复核确认。 |
| `candidate` | **暂不** | 只是线索（本表用于链接记录），采信前必须先回溯到官方原文。 |
| `deprecated` | 不引用 | 作废条目，保留在册仅供追溯。 |
| `missing` | 不引用 | 缺件占位，**不参与计算**。 |

规则：**引用的 `source_id` 必须在表内，且 status 属于前三档**。D 级材料（`source_tier = D`，含自媒体与索引）即便 status 为 `reported`，也**不得作为唯一论证依据、不进财务计算**。

## 四、两条特殊处理

1. **自媒体只作线索。** 雪球、今日头条、东方财富「财富号」三份（`SRC-SM-*`）为无署名自媒体，`source_tier = D`。`notes` 已写明：这是 **secondary lead（线索）不是证据**；文中任何**关税 / 清单 / 税率 / 禁令**说法，**必须回溯到官方原文（USTR / BIS / CBP）**才能支撑关键结论，找不到官方依据的一律标 `unverified`，**不进正式模型**。
2. **官方政策材料单独成行、可溯源。** 原产地裁定 `NY N361656`（`SRC-NY-N361656`）`issuer` 为美国海关与边境保护局（CBP）、`source_type = regulator`、`source_tier = A`。关税与原产地的正式论证**只能以该官方文件为核心依据**。

## 五、缺口清单（据实际看到的材料，不含推测）

**A 级缺口（缺的是能进模型的硬数据）**

1. **H 股募集资金净额与用途**：只有「挂牌并上市交易公告」，缺招股说明书 / 配发结果公告 / 募资用途，无法算发行对股本与现金的影响。
2. **审计机构信息**：仅 2025 年报载明普华永道中天及报告文号；2020—2024 年报与各期报告的审计机构、意见类型未逐份核验；**无审计机构变更材料**。
3. **公司公告原件**：控股股东及一致行动人减持（621 万股 / 持股降 1.46% / 套现超 53 亿元）、40 亿~80 亿元回购、2026 半年度利润分配（10 派 12 元）、2025 年度权益分派、高管换届——现**全部是 C 级媒体标题转述**，缺交易所公告原文。
4. **2025-06-30 资产负债表**：2026 半年报只给 2025-12-31 期初数，流动比率 / 资产负债率 / D/E / 摊薄 ROE 的**上年同期无法比**。
5. **单季营业成本 / 单季毛利率**：年报只披露分季度营收、归母净利、扣非、经营现金流；需用一季报、三季报原文换算（两份 PDF 已在库，本轮未提取）。
6. **前五大客户 / 供应商真实名称**：年报以「客户 A~E」「供应商 A~E」代称，客户依赖度只能定性。
7. **官方总股本 / 总市值字段**：东财个股信息接口本机被拒，市值靠「实收资本 ÷ 面值」推算，精度待核。
8. **Coherent FY2026 Q4 是否经审计**：`assurance_status` 只能标「无法判断」，且其财年与 US GAAP 口径未与 A 股对齐。

**C 级缺口（有材料但硬证据不足）**

9. **券商研报原文 PDF**：全批只有标题级摘要（`SRC-BKR-DIGEST`），盈利预测、估值方法、关键假设、主要风险**一概未取得**。
10. **2020 年报之前的定期报告**：历史 PDF 从 2020 年起，更早年份只能靠年报内拼接。
11. **可比公司原始财务**：同业里只有 Coherent 是原始财报；光迅科技、新易盛仅有媒体点评 / 报道。
12. **港股（3308.HK）专项材料**：H 股行情、AH 折溢价、港股公告原文均缺。

**完全缺件**

13. **ESG / 社会责任报告、内控评价报告**：`raw_data/` 下无此类文件。
14. **碳排放、能耗、环保投入数据**：无。
15. **治理类文件**：公司章程、独立董事、董事会 / 审计委员会构成等（`governance` 技能要的治理原件）。
16. **监管 / 诉讼 / 处罚类材料**：本轮未检到，**不代表不存在**（检索工具对这类命中率最低）。

## 六、维护

- 新导入材料 → 归档进 `raw_data/` 对应子目录 → 在本表**追加一行**，`status` 起手写 `reported`。
- 数字发生修订时**不覆盖原行**，新增一行并把旧行改 `deprecated`，保留追溯。
- 引用来源时把 `source_id` 连同 `source_tier` 一起写进正文标注，如「（来源：2025 年报，p.8，A 级）」。
