## 一、投资概要

中际旭创（300308.SZ）经营面强劲：2026H1 营收 417.78 亿元、归母净利 136.51 亿元（同比 +182.49% / +241.70%）。但估值两法方向相反——DCF 每股 126.84 元（−85.84%）对可比公司 2,033.13 元（+126.91%），方法一致性 0.00%，估值信号中性。基本面看多但信心度仅 50%；行业证据 C 级，无法验证「行业好→公司好」。评级：中性。

## 二、核心投资逻辑

1. 因为 2026H1 营业收入 417.78 亿元（累计口径，同比 +182.49%）、归母净利润 136.51 亿元（累计口径、归母，同比 +241.70%）、毛利率 46.25%（+6.91 pp）（见 analysis/fundamental.md 第三节、§4.3）→ 所以 经营面处在景气高位、盈利质量同步改善 → 但 估值快筛 PE(TTM) 48.86 倍、PB 25.07 倍、PS(TTM) 15.32 倍三只倍数全部越过偏贵阈值（见 analysis/fundamental.md §4.5）→ 因此 这是「经营强劲 + 价格已大幅透支」的组合，不是一致看多，基本面信心度仅 50%（见 analysis/fundamental.md §4.0）。

2. 因为 2026H1 自由现金流 −30.02 亿元（经营现金流 18.00 亿元 − 资本支出 48.02 亿元，由正转负）（见 analysis/fundamental.md §4.4）→ 所以 DCF 的基础 FCF 被压到 28.69 亿元（TTM 口径，取 min(当期 28.69, 3 年均值 28.76)）（见 analysis/valuation.md §4.1、§4.2 第 15 项）→ 因此 DCF 给出每股 126.84 元、折前 gap −85.84%，三档情景（悲观 60.59 / 基准 125.93 / 乐观 195.84 元）全部远低于现价（见 analysis/valuation.md §4.3.3）。

3. 因为 可比公司法采用的全部 5 家同业 P/E 中位数为 130.42 倍，被光迅科技（136.88 倍）、太辰光（162.48 倍）等低利润同业抬高（见 analysis/valuation.md §4.4.1、§4.4.3）→ 所以 仅把同业集合换成龙头 2 家（新易盛 / 华工），折前 gap 即从 +126.91% 翻到 −7.77%（见 analysis/valuation.md §4.4.3）→ 因此 可比公司法给出的 2,033.13 元属机制性偏高，与 DCF 结论一样都不稳，两法相差约 16 倍、方向相反（见 analysis/valuation.md §4.0）。

4. 因为 行业分析证据等级为 C 级，五力中无一力具备完整量化判据（4 力纯定性）（见 analysis/industry.md §一、§4.1、§六）→ 所以 行业至公司业绩的传导链三环（份额 / 产能 / 价格）全部断开，「AI 算力需求爆发 → 光模块需求增长 → 中际旭创业绩增长」在本轮材料内无法验证 → 因此 行业景气不能作为支持公司估值的论据（见 analysis/industry.md §4.1 传导机制说明）。

5. 因为 2026Q2 单季经营现金流约 −15.68 亿元（= 半年报累计 18.00 − 一季报 33.68），同期存货由 126.81 亿元升至 198.26 亿元、应收账款由 63.0 亿元升至 150.9 亿元（见 analysis/fundamental.md §4.4）→ 所以 存在两种方向相反的解释：为 1.6T 放量提前备货（成长性投入）或回款质量恶化（见 analysis/fundamental.md §4.4、analysis/valuation.md §5.3）→ 因此 这一成因未证实的缺口是本次判断的关键变量，两种解释对投资含义相反。

## 四、估值分析

当前价格基准：2026-09-17 收盘价 **896.00 元**，总市值 9,992.50 亿元（收盘价 × 推算总股本，`[待核实]`）（见 analysis/valuation.md §2.2）。

**两条路给出方向相反的结论（这是本节最需要看清的一点）：**

| 方法 | 权重 | 是否可执行 | 每股价值（元） | 折前 gap |
| --- | --- | --- | --- | --- |
| DCF | 40% | 可执行 | 126.84 | −85.84%（严重高估） |
| 可比公司法 | 35% | 可执行（仅 P/E） | 2,033.13 | +126.91%（严重低估） |
| 所有者收益法 | 25% | **不可执行**（缺折旧摊销） | — | — |

- **DCF**：基础 FCF 28.69 亿元（TTM），WACC 9.73%，三阶段增长 35% / 15% / 终值 3%。三档情景（悲观 60.59 / 基准 125.93 / 乐观 195.84 元）全部远低于现价；其「高估」信号源于**利润与现金流的巨额缺口**（TTM 归母净利 204.53 亿元 vs TTM FCF 28.69 亿元），非增长假设保守（见 analysis/valuation.md §4.3.3）。
- **可比公司法**：按全部 5 家同业 P/E 中位数 130.42 倍、施加 15% 折价得隐含 P/E 110.86 倍。中位数被光迅科技（136.88 倍）、太辰光（162.48 倍）等低利润同业抬高，套到全行业盈利体量最大的标的上系统性偏高。敏感性：仅取龙头 2 家即降至 826.42 元（gap −7.77%）；P/B 旁证 739.76 元（gap −17.44%）（见 analysis/valuation.md §4.4.2、§4.4.3）。

**加权结果不可用 —— 必须点明。** 折前加权 gap +13.44%、每股 1,016.44 元；折后（施加 25% 安全边际）762.33 元、gap −14.92%。但**方法一致性为 0.00%**：DCF（−85.84%）与可比公司（+126.91%）的 gap 相差 212.76 pp，方向相反。**加权 gap 落在 +13% 附近纯属两法偶然抵消，而非趋同**（见 analysis/valuation.md §4.6）。因此 1,016.44 元不构成「合理价」。

**估值区间不是可用的目标价区间。** 报告给出 **95.13 ~ 1,524.85 元/股**，并明确这是**方法间区间**（反映方法本身的分歧）、**不是置信区间**；区间宽达 16 倍，恰恰说明两个方法几乎无法调和（见 analysis/valuation.md §4.0）。此外，折后 gap 要转正，折前 gap 须 ≥ +33.33%，本次折前仅 +13.44%，故折后 gap 为负（−14.92%），**不能读成「只比折前低一点」**（见 analysis/valuation.md §4.0）。

**结论：估值信号中性。** 这里的「中性」含义是「方法之间打平、无一致观点」，**不是「估值合理」**（见 analysis/valuation.md §一、§4.6）。

**证据等级：C 级。** 研报与新闻**全部只有标题级、无一份正文**（本机 WebFetch 被网络策略拦截），无法建立任何「市场一致预期」（见 analysis/industry.md §一、§2.1）。本备忘录因此不引用「机构普遍看好」「券商一致预期」类表述。

**市场份额：无数据。** 行业集中度（CR5 / CR10）、公司相对份额、前五大客户占比、产能利用率等关键判据**全部未披露**（见 analysis/industry.md §3.1、§六）。可得的只是规模事实——TTM 归母净利润 204.53 亿元高于同业（新易盛 131.19 亿元等），但**这是「规模」而非「份额第一」**（见 analysis/industry.md §4.2 优势条目）。

**竞争优势：** 公司侧有营收利润高速增长、盈利能力提升、净利润规模同业最大、资本开支大幅上行、财务结构稳健五条（见 analysis/industry.md §4.2）；劣势侧有经营现金流与净利润背离、应收账款与存货大幅攀升、控股股东大额减持（621 万股 / 套现超 53 亿元，C 级 `[待核实]`）、港股首日破发等条目（见 analysis/industry.md §4.2）。

**行业趋势（均为 C 级线索或判断）：** ① 需求侧向上（AI 算力资本开支扩张 + 1.6T 规模放量）；② 技术侧迭代明确（800G / 1.6T 向 NPO / CPO 演进）；③ 供给侧边际改善（关键物料由紧缺转向缓解，属短期判断、保质期短）；④ 竞争格局未固化（可比公司 PE 区间 45~162 倍，定价分歧大）；⑤ **传导未验证**（见 analysis/industry.md §4.3）。

**竞争格局（Porter 五力）不足以量化。** 五力中**无一力具备完整量化判据**：行业现有竞争程度、供应商议价能力、新进入者威胁、替代品威胁**共 4 力纯定性**；客户议价能力仅有一项计算指标辅助（应收账款周转天数 ≈ 59.85 天），但其核心判据（前五大客户收入占比）仍未取得（见 analysis/industry.md §4.1、§六）。

**政策风险：本节无条目可列。** 本轮材料未检到任何带政策名称 / 发布机关 / 发布日期的具体政策（已检索政策 / 监管 / 关税 / 出口 / 补贴 / 工信部 / 发改委等关键词），按规则不凭标题猜文号，故不列条目。**这是数据缺口，不等于无政策风险** —— 出口管制、贸易与关税是光模块行业的潜在重要外部变量（见 analysis/industry.md §5.2）。

**本节最重要的一处限制：传导链断开。** 「AI 算力需求爆发 → 光模块需求增长 → 中际旭创业绩增长」这条链，中间至少缺三环：份额能否守住、产能能否跟上、增量会不会被价格战吃掉。三环在本轮材料内**全部断开**，故**不对传导成立与否下结论**——数据缺口不等于负面结论（见 analysis/industry.md §4.1）。

## 七、投资结论与建议

**评级：中性。**

评级依据：估值报告结论为「两法打架、中性」（方法一致性 0.00%，DCF 与可比公司方向相反）（见 analysis/valuation.md §4.6）；基本面整体看多，但信心度仅 50%，四个子信号为「盈利看多 / 成长看多 / 财务健康中性 / **估值合理性看空**」，分歧明显（见 analysis/fundamental.md §4.0）；行业分析证据等级 C 级，无法提供方向性支撑（见 analysis/industry.md §一）。三份报告合并后**不产生方向性依据**，故评级为中性。

**目标价区间（分方法列示，不给合并区间）：**

- **DCF 法**：每股 **126.84 元**。关键假设：基础 FCF 28.69 亿元（TTM 口径）、WACC 9.73%（Beta 1.40、ERP 5.50%、Rf 2.00%）、高增长期 35% / 过渡期 15% / 终值 3%、情景概率 20 / 60 / 20。三档情景区间 **60.59 ~ 195.84 元**（见 analysis/valuation.md §4.2、§4.3.3）。
