# templates/cover/ —— CFA 官方封面与封底

**封面已到（2026-09-19），封底官方没有。**

按 `output-format.md` §1.5，封面封底必须用 CFA 协会规定的模板，不计入正文、
不计页码。

## 放什么

| 文件 | 说明 | 状态 |
| --- | --- | --- |
| `cover-official.docx` | 官方前封面，**Word 可编辑版** | **已到** |
| `back-cover-official.*` | 官方封底 | **官方未提供**，见 `来源.md` |
| `来源.md` | 从哪拿到的、哪天拿到的、对应哪一版规则附件 | 已写 |

**官方只发前封面。** 规则正文通篇只提 `the front cover page provided by CFA Institute`，
Appendix C 也只给前封面。校赛说明要求「封面和封底」，但 CFA 这一侧没有封底模板 ——
先按「只有封面」做，同时向赛区主办方确认「封底」指什么，**确认前不要自己造一个**。
详情见 `来源.md`。

`cover-official.docx` 里只有高亮处的字段（队名、赛区名、Disclosures 三个 `[...]` 空）
可填，**其余内容含 CFA 标志一字不得改**。

## 拿到之前怎么办

用 `[[待填]]` 占位块顶上，页面上大字标明「CFA 官方封面模板待替换」。

**不许自己画一个「看起来像」的封面当作定稿。** 封面是赛事方给的，
自造的一旦被核对就是版式不合规 —— 代价不是排版难看，是资格问题。

## 封面封底不计页码

`tools/pdf/header.tex` 里已经留好 `coverpage` 环境。Markdown 里这样写：

```
::: {.cover}
（封面内容）
:::
```

这个块会被单独排成一页、不出页码，且不计入正文页数。

## 封面封底不参与门禁扫描

`tools/model/gate_check.py` 只扫正文与附录。封面里的公司名、日期这些
**由赛事模板决定的字段**，不受「四个日期必须一致」那套校验约束。
