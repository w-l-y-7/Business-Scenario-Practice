# figures/ —— 报告图片存放处

研报里用到的图片放这里。**只放图片本身，不放源数据。**

## 放什么

| 类型 | 例子 | 命名 |
| --- | --- | --- |
| 正文插图 | 收入结构图、可比公司倍数散点 | `F01-收入结构.png` |
| 附录插图 | 计算底稿里的示意图 | `A01-现金桥示意.png` |
| 封面封底素材 | 官方封面里要用的图 | 见 `templates/cover/` |

## 不放什么

- **原始财报 PDF** → 放 `raw_data/`
- **模型算出来的表** → 放 `model/results/`，表格用 Markdown，不截图
- **网上直接下的图** → 可以当插图，但**不能单独当证据**，来源照样要在 `analysis/` 里逐条登记等级与三个属性

## 命名与格式

- 文件名用 `F{两位序号}-{中文描述}`，序号与正文出现顺序一致；附录用 `A` 开头
- 位图用 **PNG**，不要 JPG —— 表格线和小字会糊
- 矢量图用 PDF，**字体必须嵌进去**（`pdffonts 文件.pdf` 能查，字体那列不能是空）
- 分辨率 ≥ 300 dpi。A4 版心宽约 176 mm，横跨版心的图至少 **2100 px** 宽

## 谁生成

**本项目不自动生成图片。** 需要配图时，由使用者按定稿数据自行绘制后放进来 ——
项目里的程序只产出数字和表格，不产图。需要图形化时，本项目只说明该画什么。

## 怎么在文稿里引用

Markdown 里这样写：

```
![图 1 中际旭创收入结构（2023—2025）](figures/F01-收入结构.png)

::: {.source}
数据来源：2025 年年报，第 88 页，A 级。图由使用者按定稿数据绘制。
:::
```

**图号、图题、来源块三样缺一不可。** 只有一张图没有来源，在合规上等于没写完。

排版上 `![...]` 后面的方括号内容会渲染成图题；图会被自动限制在版心宽度内，
不会冲出页面。

## 页数代价

横图一张就吃掉小半页，而正文 10 页封顶。按 `output-format.md` §2.2 的配比，
**正文里放 2—3 张图就到顶了**，再多就要从别的节腾地方。配图前先算页数。
