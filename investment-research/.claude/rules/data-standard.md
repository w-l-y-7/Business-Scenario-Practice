# 数据规范

本项目所有数字的准入标准。任何一份产出（原始材料、分析报告、投资研报）里的每个数字，都要过这一关。

一句话原则：**数字必须能回答三个问题 —— 从哪来、什么时点、什么口径。答不上来的，标 `[待核实]`，不许当成已知事实写。**

---

## 一、来源标注

### 1.1 正文里的数字（固定格式）

每个数字后面紧跟来源，四种写法对应四类数据，**照抄括号里的结构**：

| 数据类型 | 格式 |
| --- | --- |
| 财报数据 | `营业收入 1,234.56 亿元（来源：2025 年三季报，第 12 页）` |
| 研报数据 | `行业增速 10%~12%（来源：中金，《白酒行业深度》，2026-08-15）` |
| 新闻信息 | `消费税调整落地（来源：财新，2026-09-10）` |
| 计算指标 | `毛利率 46.20%（计算方式：（营业收入 − 营业成本）/ 营业收入，基于 2025 年三季报）` |

**附加标注**（本项目要求，跟在来源后面）：

- **口径**写在指标名里 —— `营业收入（累计口径）1,234.56 亿元`。至少标「累计还是单季」和「单位」；涉及利润的加标「归母还是含少数股东」。
- **可信度等级**跟在来源末尾 —— `（来源：中金，《白酒行业深度》，2026-08-15，B 级）`。

#### 成品报告里的英文写法（`output/investment-report.md` 专用）

成品是英文提交件，来源标注要译成英文，**结构一一对应**：

| 数据类型 | 格式 |
| --- | --- |
| 财报数据 | `Revenue of CNY 123,456 mn (Source: 2025 Interim Report, p. 12, Grade A)` |
| 研报数据 | `Industry growth of 10%–12% (Source: CICC, China Baijiu Sector Deep Dive, 2026-08-15, Grade B)` |
| 新闻信息 | `Consumption tax adjustment implemented (Source: Caixin, 2026-09-10, Grade C)` |
| 计算指标 | `Gross margin of 46.20% (Calculation: (Revenue − COGS) / Revenue, based on 2025 Interim Report)` |

口径写成英文术语：累计口径 = `cumulative`，单季 = `single quarter`，归母 = `attributable to shareholders`，扣非 = `adjusted / ex-non-recurring`。

**中间报告仍用中文写法**，只有成品转英文。translate 时不要改变数字和口径 —— 只换写法，不换内容。

### 1.2 原始材料文件（raw_data/ 下的文件）

每个文件**开头必须有来源块**：

```
> **来源**：东方财富网 · 贵州茅台（600519）2025 年三季报
> **链接/文件**：https://... 或 原始文件名.pdf
> **采集日期**：2026-09-12
> **发布时间**：2025-10-28
> **可信度**：A
> **审计/鉴证**：未经审计
> **事实或观点**：事实
> **交叉核验**：单一来源
> **采集人**：data-collector
```

- 「链接/文件」要能让人**顺着找回去**。网页给完整 URL，本地文件给文件名。
- 采集日期写**实际抓取的那天**，不是报告发布日。
- 链接拿不到就写「本地文件，无公开链接」，**不许编一个假链接**。
- **「审计/鉴证」「事实或观点」「交叉核验」三个字段见 §4.2，取值照那里抄。** 财报类必标审计状态；研报、媒体、公司自述类必标事实或观点；影响结论的关键数字必标交叉核验情况。一项确实不适用才留空，并在后面写「不适用」及理由 —— **不许整行省略**。

### 1.3 表格

同一张表全部来自同一来源 → 表下统一标注一行即可，不必每格重复。来源混杂的表 → 在备注列逐个标。

## 二、口径标注

### 2.1 必须说明的口径

| 维度 | 可能的取值 | 为什么重要 |
| --- | --- | --- |
| 期间 | 累计口径 / 单季口径 | A 股法定披露是累计，中报是上半年、三季报是前三季。拿累计当单季比会错得很离谱 |
| 利润归属 | 归母净利润 / 含少数股东权益的净利润 | 两者能差出一大截 |
| 归属范围 | 归母口径 / 合并口径 | 利润、折旧摊销、资本支出、营运资本变动**必须同属一个口径**。用归母净利润配合并范围的现金流，会把少数股东对应的那部分混进来 —— 混搭不报错，只会悄悄算错 |
| 单位 | 元 / 万元 / 亿元 | 差 100 倍的坑，转换前先核对 |
| 时点 | 期末时点数 / 期间发生数 | 资产负债表是时点数，利润表是期间数，不能用同一种方式算同比 |
| 调整 | 原始披露值 / 调整后（扣非） | 扣非剔除了非经常性损益 |

每个数字至少标**期间 + 单位**，涉及利润的加标**归属**。

### 2.2 口径换算

- A 股单季 = 相邻累计相减：Q2 单季 = 中报 − 一季报；Q3 单季 = 三季报 − 中报；Q4 单季 = 年报 − 三季报；Q1 单季 = 一季报本身。
- 同比/环比**必须同口径比**：累计对累计、单季对单季。跨口径比出来的数一律作废。
- 换算过程要留痕：按「计算指标」格式标出公式与原数据来源。

### 2.3 四个日期，四件事

报告里出现「日期」的地方不止一处，**它们是四个互相独立的字段，不许合并、不许用其中一个顶替另一个**：

| 字段 | 含义 | 说明 |
| --- | --- | --- |
| **信息截止时间** | 资料查到哪一天 | 决定「有没有用上最新公告」。定不下来就写实际检索日 |
| **行情日期** | 股价、市值取自哪一天 | **不等于估值基准日**。行情是市场给的，会在休市日空缺 |
| **估值基准日** | 估值站在哪一天 | 折现的起点。股本、债务、资产负债表口径都以此日为准 |
| **目标日期** | 目标价对应哪一天 | **行情日期 + 12 个月**（定义见 `output-format.md` §1.2，此处不另立口径） |

**目标价必须写明相对哪个基准日、多长期限。** 光写「目标价 X 元」而不写这两个，等于没说清楚这个数的有效期。

**行情日期遇休市，取前一个交易日，并把实际交易日如实写出来** —— 写成 `as of 2026-09-18（实际交易日 2026-09-17）`。首轮行情日期定为 **2026-09-18**；该日究竟是不是交易日**尚未核实**，用之前先查一次交易日历。

**四个字段都要能对上模型。** 统一模型的 `meta` 里同名四字段与成品报告里的值必须一致，不一致由输出门禁拦下。

## 三、数字格式

| 类型 | 格式 | 示例 |
| --- | --- | --- |
| 金额 | 亿元，保留 2 位小数 | `1,234.56 亿元` |
| 比率 | 百分数，保留 2 位小数 | `46.20%` |
| 比率变动 | 百分点（pp），保留 2 位小数 | `+2.35 pp` |
| 增速 | 百分数，保留 2 位小数 | `+12.34%` |
| 倍数 | 保留 2 位小数 | `18.75 倍` |
| 日期 | YYYY-MM-DD | `2026-09-12` |
| 报告期 | YYYY 年报 / YYYYQ1~Q4 | `2025 年三季报` / `2025Q3` |

- 内部计算用**原始值精确算**，只在展示时四舍五入。别拿四舍五入后的数再算下一层。
- 分母为负（亏损）时，算出的增速没有意义 → 不写百分数，改写「由盈转亏」「亏损收窄 X 亿元」这类描述。

## 四、来源分级与三个属性

### 4.1 来源等级（A / B / C / D）

每条来源标一个等级。**评的是来源本身，不是数字好不好看。**

| 等级 | 是什么 | 例子 |
| --- | --- | --- |
| **A** | 官方原始披露，法律上要担责 | 交易所公告、公司年报/半年报/季报原文、招股说明书、监管处罚决定书 |
| **B** | 专业机构产出，有署名有依据 | 券商研报、数据终端（Wind / 同花顺 / 东方财富 Choice）、行业协会统计 |
| **C** | 财经媒体、公司自述 | 财新、证券时报等报道，公司官网新闻稿，业绩说明会问答 |
| **D** | 无署名、无从核实 | 自媒体、论坛帖、微信群截图、未具名「据知情人士」 |

使用规则：

- **A、B 级可直接用于分析**。
- **C 级可用，但必须在正文标注「据媒体报道」，且不能作为唯一的论证依据** —— 要有 A 或 B 级佐证。
- **D 级默认不用**。确有必要（比如作为「市场情绪」的观察对象）时，必须显式写「未经证实，仅作舆情参考」，且**绝不进入财务计算**。

同一个数字有多个来源时，取**等级最高的那个**，并在备注里写清其他来源的分歧。

### 4.2 三个正交属性（每条来源都要标）

等级说的是**「谁发的」**，属性说的是**「这条证据有多硬」**。两者独立 —— 一份 A 级来源（公司公告）可以是「事实」，一份 B 级来源（券商研报）常常是「观点」。**只标等级不标属性，等于只说了来源是谁。**

| 属性 | 取值 | 哪些来源必须标 |
| --- | --- | --- |
| **审计 / 鉴证状态** | 已审计 / 已审阅 / 经第三方鉴证 / 未经审计 / 无法判断 | 财报类、ESG 报告类、内控评价报告类。**季报和半年报未经审计是常态，必须标出来** |
| **事实还是观点** | 事实 / 观点 / 混合 | 券商研报、媒体报道、公司自述。**观点只能当观点引用** |
| **是否交叉核验** | 已交叉核验（写明几路）/ 单一来源 | 影响结论的关键数字。**单一来源要在正文点明** |

三条硬规矩：

- **未经审计的要标出来。** 半年报、季报没有审计意见，它和年报不是同一档可信度。拿未审计数据算出来的结论，要说明这一层。
- **观点不能当事实写。** 券商目标价、媒体判断、管理层对前景的表述，都是观点。引用可以，但要标「这是观点」，且不能作为唯一论证依据。**把券商目标价当成「这家公司值多少钱」的事实陈述，是最常见的越界。**
- **关键数字单一来源要提示。** 影响结论的数字只有一路来源、没有第二路可核 → 标出来，让读者知道它没有独立佐证。

### 4.3 公司 ESG / 社会责任报告怎么定级（不要机械归 C）

公司自己发的 ESG 报告**不一律按 C 级处理**。整份报告标一个 C，是把「公司自愿披露」和「受监管强制披露」混成了一件事。按下面三条拆：

| 情况 | 等级 | 理由 |
| --- | --- | --- |
| 报告**经第三方独立鉴证**（如 ISAE 3000 鉴证意见） | **B** | 有外部机构背书，不再是纯自述 |
| 报告未鉴证，但该指标**同时出现在法定披露文件**里（年报「环保投入」、监管处罚公示、排污许可） | **A** 或 **B** | 以法定披露的那一份为准，ESG 报告只作补充 |
| 报告未鉴证，且指标是**公司自愿披露** | **C** | 纯自述，须有 A 或 B 级佐证才能进结论 |

**判断顺序**：先看有没有第三方鉴证意见 → 再看这个指标是不是监管强制披露项 → 都不是，才按 C 级处理。同一个数据点在 ESG 报告和年报里都出现、且数字打架时，**以年报为准**并在备注写清分歧。

### 4.4 等级和属性都不等于模型正确

**评的是来源，不是模型。** A 级只说明「这个数是公司自己披露的、法律上要担责」，**不说明拿它算出来的结论对**。A 级的营业收入配上错的口径（拿累计当单季）、错的期间（拿报告期末当基准日）、错的折现假设，算出来的估值一样是错的 —— 而错误藏在模型里，来源等级再高也照不出来。

判断结论可不可靠，要问的是另外几件事：口径核验做了没有、现金流与折现率配没配对、有没有独立复算过、敏感性测没测。**「输入是 A 级」不能替代这几样。**

## 五、无法确认来源时怎么办

按项目 `CLAUDE.md` 的要求：**标记为 `[待核实]`，并在审阅阶段提醒分析师。**

具体展开成这几种情况：

| 情况 | 怎么写 |
| --- | --- |
| 来源说不清是谁发的、什么时候发的 | `[待核实]` + 说明卡在哪 |
| 来源里有，但这取决于版本/口径 | 写数值 + `[待核实：口径]` + 说清疑问点 |
| **本轮没去找这项** | `[未检索]` + 写明为什么没查（超出本轮范围 / 资源限制） |
| **去找了，确实没有这项披露** | 「未披露」+ 写明查了哪些来源 |
| 该对比不适用（如新上市公司没有上年同期） | 写「—」 |
| 需要估算 | 标 `[估算]` + 估算方法与依据，**不与其他实测数字混在同一列** |

**`[未检索]` 和「未披露」不能混用。** 前者是**我们的工作没做到**，后者是**公司没说**。把「没去查」写成「未披露」，等于把自己的缺口算到公司头上 —— 读者会以为公司隐瞒，而真相是这份报告还没查完。反过来，把「公司确实没披露」写成本轮没查，就等于放过了「该公司披露不足」这个结论本身。

**「未披露」必须写明查了哪些来源。** 只写「未披露」，读者分不清是查过没有。写成「未披露（已查：2025 年报 §员工情况、ESG 报告、生态环境局处罚公示）」才有信息量。

`[待核实]` 的项要在报告里**汇总成一节**（见 `.claude/rules/output-format.md`），不能散落在正文里被读者漏掉。

**四条禁止**：不编数、不用记忆里的数、不拿估算冒充实测、不因为「这里应该有个数」就补一个。

数据缺口积累到影响结论时，在报告里单列一节，把缺什么、为什么缺、缺了会影响哪部分结论说清楚。
