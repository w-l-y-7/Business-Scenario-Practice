# industry：行业分析

读 `raw_data/reports/`（券商研报）和 `raw_data/news/`（新闻舆情），产出 `analysis/industry.md`，对应 CFA 研报第 ② 节 Industry Overview and Competitive Positioning。

**行业分析最容易写成正确的废话。** 「竞争激烈」「行业前景广阔」这类句子不用看材料也能写，写了等于没写。这个技能的纪律是：**每一句判断后面都要挂得住一条数据** —— 行业规模配数字，五力的每一力配可核判据，SWOT 每一条附来源。挂不住的判断，删掉。

## 速查表

| 模块 | 产出 | 硬要求 |
| --- | --- | --- |
| 行业概况 | 行业规模、增速、产业链结构、发展阶段 | 规模与增速必须**带数值和口径**（哪一年、哪个统计口径、什么单位），拿不到就标 `[待核实]`，不许写「市场规模巨大」 |
| 竞争格局 | 五力评级表（高 / 中 / 低） | 每一力**量化判据优先**，拿不到量化就标 `[待核实]` 并声明只用了定性 |
| 竞争地位 | 公司相对份额与定位 | 市占率、排名、产能、客户结构**至少拿到一项**；一项都拿不到时明写「无法定位公司竞争地位」，不硬下结论 |
| SWOT | 四象限，每象限 3-5 条 | **视角是「公司在本行业中」**：优势劣势看公司，机会威胁看行业 |
| 行业趋势 | ≤ 200 字总结 | 每条趋势要有依据，不写「前景广阔」这类话 |
| 时效标注 | 每条判断标来源日期 + 距基准日天数 | **不套 180 天过期规则**；保质期长短看判断类型，由读者判断 |

## 一、动手前先定三件事

1. **标的与行业** —— 公司落在哪个行业口径（参照 `raw_data/reports/` 里券商研报的行业归类，别自己拍一个）
2. **材料范围** —— 手上有几份研报、多少条新闻
3. **数据可得性** —— 客户集中度、供应商集中度这类数据只在财报里，先看看拿不拿得到

**可以只读 `raw_data/earnings/`。** `CLAUDE.md` 禁止的是跨目录**写入**，读取不受限。五力里的客户集中度、应收账款周转天数这些指标只有财报里有 —— 该读就读，不要因为「行业分析不该看财报」就放着现成的数据不用、改去猜。

## 二、行业概况

先回答「这是多大一个行业、往哪走、钱怎么赚」，再谈竞争。**跳过概况直接上五力，读者不知道这个行业值不值得看，判断就悬空了。**

四个必填项：

| 项 | 要什么 | 拿不到怎么办 |
| --- | --- | --- |
| 行业规模 | 最近一个完整年度的市场规模（金额或出货量），**注明统计口径和来源** | 标 `[待核实]`，写清找了哪些来源都没拿到 |
| 行业增速 | 近三年增速 + 未来预期增速，注明是实际值还是预测值 | 同上；预测值必须标明是哪家机构的预测 |
| 产业链结构 | 上游（原材料 / 零部件）→ 中游（本行业）→ 下游（应用 / 客户），公司落在哪一环 | 依据不足时只画结构不标份额 |
| 发展阶段 | 导入期 / 成长期 / 成熟期 / 衰退期，**并给出判断依据** | 标 `[估算]` 并声明无来源支撑 |

**「市场规模巨大」「快速增长」这类话一律不许出现。** 判断标准同 §六：把行业名换成任何一个行业还成立吗？成立就删。

行业口径（按哪套分类、边界怎么划）在这一节开头说清楚 —— 同一个词在不同分类体系下指的不是一回事。

## 三、竞争格局：Porter 五力

五力缺一不可。**行业现有竞争程度**是最容易被漏掉的一力，但它往往最直接决定盈利水平 —— 集中度低、产能过剩、打价格战的行业，供应商和客户两头再温和也没用。

每一力配**一条量化判据（优先）+ 一条定性判据（兜底）**：

| 力 | 量化判据 | 定性判据 |
| --- | --- | --- |
| 行业现有竞争程度 | CR5 / CR10 集中度、产能利用率、近三年产品均价变动 | 竞争手段（价格 / 服务 / 技术）、退出壁垒高低 |
| 供应商议价能力 | 前五大供应商采购占比、合格供应商数量 | 核心原材料可替代性、供应商转换成本 |
| 客户议价能力 | **前五大客户收入占比 ≥ 50% → 高**、应收账款周转天数 | 客户转换成本、产品标准化程度 |
| 新进入者威胁 | 牌照 / 资质要求、单位产能资本开支、专利壁垒 | 规模经济、先发优势、渠道壁垒 |
| 替代品威胁 | 替代技术与现有技术的成本差（%）、替代品渗透率及增速 | 替代技术成熟度、切换成本 |

**判断规则**：

1. **量化判据优先**。拿得到数就用数判，并在表里写出数值。
2. 量化拿不到 → 标 `[待核实]`，**并声明这一力仅凭定性判断**。不许用「行业壁垒较高」这种模糊表述冒充结论。
3. 每一力的评级后面**必须注明依据来源**（哪份研报、哪条新闻、哪页财报）。
4. 同一力有多个来源冲突 → 全留、各标来源、标 `[待核实]`。

评级用**高 / 中 / 低**三档。高 = 该力量对行业盈利的压迫强（新进入者威胁高 = 容易进 = 对在位者不利）。

## 四、竞争地位

五力描述的是**行业**的竞争强度，这一节描述的是**公司**在这个行业里站的位置。CFA 那节标题把两者并列，是有道理的 —— 行业好不等于公司能吃到，中间隔的就是竞争地位。

四项必查，**至少拿到一项**才算能定位：

| 项 | 要什么 | 数据来源 |
| --- | --- | --- |
| 市场份额 | 公司市占率（注明口径：按收入还是按出货量）、近三年变动趋势 | `raw_data/reports/`、`raw_data/earnings/` |
| 行业排名 | 第几名、与前后名的差距 | `raw_data/reports/` |
| 产能与产能利用率 | 公司产能、行业总产能、利用率 | `raw_data/reports/`、`raw_data/earnings/` |
| 客户结构 | 前五大客户占比、客户集中度趋势 | `raw_data/earnings/`（财报附注） |

**四项一项都拿不到 → 明写「本报告无数据支撑公司竞争地位判断」，不要用「行业领先」「头部厂商」这类没有出处的说法糊过去。** 这是行业分析最容易出事的地方：标题级材料里天天出现「龙头」，但那是媒体修辞，不是市场份额。

拿到数据的项要**说清与同行的相对位置**（比谁高、差多少），只报公司自己的一个绝对值等于没定位。

## 五、SWOT：公司在本行业中

四象限的**视角是「目标公司在本行业中的处境」**，不是行业本身：

| 象限 | 看谁 | 数据主要来自 |
| --- | --- | --- |
| **优势** Strengths | 公司自身 | `raw_data/earnings/`、`raw_data/reports/` |
| **劣势** Weaknesses | 公司自身 | `raw_data/earnings/`、`raw_data/reports/` |
| **机会** Opportunities | 行业 | `raw_data/reports/`、`raw_data/news/` |
| **威胁** Threats | 行业 | `raw_data/reports/`、`raw_data/news/` |

每条要求：

- 每象限 **3-5 条**，不足 3 条就写实际条数并说明为什么少
- **每条附数据来源**，格式照 `data-standard.md` §1.1
- 优势劣势写公司**可验证的事实**（市占率、毛利率、研发投入），不写「管理优秀」这类无法核实的形容词
- 机会威胁写**行业层面的变化**（政策、技术路线、需求结构），并标明这是判断不是事实

**行业层面的事不要写成公司的事。** 比如「AI 算力需求爆发」是机会（行业级），「新华三在政企市场的份额」才是优势（公司级）。放错象限会让整个 SWOT 失去意义。

## 六、行业趋势总结

**200 字以内**，3-5 条趋势，每条一句话。

要求：

- 每条趋势**挂一条依据**（研报观点或新闻事件，带来源）
- 不写「前景广阔」「竞争日趋激烈」这类放之四海皆准的话 —— 判断标准是：**把公司名换成同行任何一家，这句话还成立吗？** 成立就说明它没有信息量，删掉
- 趋势要能指回后文的五力和 SWOT

## 七、时效标注

每条行业判断后面标**来源日期 + 距评估基准日的天数**：

```
AI 算力资本开支持续扩张（来源：中金，《ICT 行业深度》，2026-06-20，B 级；距今 84 天）
```

**不套用 `report-digest` 那套 180 天过期规则。** 行业判断的保质期跟研报评级不一样：

| 判断类型 | 保质期 | 例子 |
| --- | --- | --- |
| 结构性判断 | 较长 | 技术路线演进、政策方向、竞争格局成因 |
| 短期判断 | 较短 | 产品价格、供需缺口、库存水平、季度景气度 |

标出日期和间隔，让读者自己判断这条还能不能用。一刀切标「过期」会两边都错 —— 一条两年前的技术路线判断可能仍然成立，一条两个月前的价格判断可能已经失效。

## 九、交棒

写完汇报：**行业规模与增速拿到了没有、五力评级分布、公司竞争地位是否定位成功、SWOT 各象限条数、有几力只用了定性判断、什么数据缺口**，并说明文件落在哪。

然后**停下**，等「人在回路」第 3 个节点（**分析逻辑审查**）：因果关系是否成立、结论有没有过度外推。行业分析特别容易犯的错是**把行业趋势直接外推成公司业绩** —— 「行业要增长」不等于「这家公司能吃到」,这两步之间必须说清楚传导机制。

**不越过节点自动往下走。**

## 必须遵守的规则

1. **不编数**。量化判据拿不到就标 `[待核实]` 并声明只用了定性判断，不拿模糊表述冒充结论。
2. **只在 `analysis/industry.md` 写入**，不碰 `output/`；`raw_data/` 可以**只读**（尤其是 earnings），但不写。
3. **每条判断挂得住依据**。行业规模与增速带口径，五力逐力标来源，竞争地位逐项标口径，SWOT 逐条标来源，趋势逐条标来源。
4. **不写正确的废话**。把公司名换成同行还成立的话，删掉。
5. **不用「龙头」「行业领先」代替市场份额**。这类词在没有市占率数据支撑时是媒体修辞，不是结论。四项竞争地位指标一项都拿不到就明写「无法定位」，不硬下结论。
6. **不在弱势证据上做强结论**。全部材料都是 C 级媒体转述时，结论措辞要相应收敛，并在结论摘要里说明证据等级。
7. **不越人在回路节点**。分析逻辑要等确认。
