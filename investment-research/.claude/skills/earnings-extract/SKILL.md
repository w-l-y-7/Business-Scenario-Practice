# earnings-extract：财报数据提取

把一份财报（或它的转述）里的关键财务指标提出来，落成 `raw_data/earnings/` 下的一个文件。

**产出是原材料，不是结论。** 下游的 financial-analyst 和 valuation 都建在这份文件上，所以把来源和口径标清楚，比多提几个指标值钱。没标来源的数字，下游一律不能当已知事实用，这趟就白跑了。

## 速查表

动手前先扫一眼：提哪些、每个卡什么口径。

| 组 | 指标 | 卡死的口径要求 |
| --- | --- | --- |
| 盈利能力 | 营业收入、净利润、毛利率、净利润率、ROE、经营利润率 | 利润类必须标**归母还是含少数股东**；ROE 标**加权还是摊薄** |
| 成长性 | 收入增长率、盈利增长率、账面价值增长率 | 必须**同口径比** —— 累计对累计、单季对单季，跨口径比出来的数一律作废 |
| 财务健康 | 流动比率、资产负债率、D/E、经营性现金流、FCF | 前三个是**期末时点数**，后两个是**期间发生数**，不能用同一种方式算同比 |
| 估值参考 | P/E、P/B、P/S、EV/EBITDA | 来源是**行情数据**不是财报；分母标**TTM 还是最近一期年报** |

四组的每个数字，无论哪一组，都至少标**期间 + 单位**；涉及利润的加标**归属**。

## 一、动手前先定三件事

1. **标的** —— 公司名称 + 证券代码，能带市场更好（如 `000938.SZ`）
2. **报告期** —— 哪一期（`2026 年半年报` / `2025 年三季报` / `2025Q3`）
3. **输入** —— 有没有 PDF 原文；没有的话转述材料在哪

用户给全了就直接做，不要反问一遍。缺了才问，一次问清。

## 二、先判输入是几手材料

这一步决定整份文件的来源等级，别跳过。

- **PDF 原文优先**（年报/半年报/季报正文、交易所公告）→ 可信度 **A**，每个数字标页码。
- **拿不到原文** → 可以退到二手转述（券商研报 B 级、财经媒体 C 级），但三件事必须做到：逐条标出处（媒体名 + 标题或日期）、整份文件按最低来源降级标注、在「数据缺口」节写明**未取得原文**并提醒下游引用前回原文核实。
- **不编链接**。拿不到就写「本地文件，无公开链接」或「原文未取得」。`data-standard.md` 把编造链接列为红线。

同一指标有多个来源 → **全留**，各自标来源，加 `[待核实]`，**不挑一个当正确答案**。这是采集环节，拍板是分析师的事。

## 三、提取四组指标

### 3.1 盈利能力

| 指标 | 提什么 |
| --- | --- |
| 营业收入 | 本期值 + 同比增长率；标累计/单季、单位 |
| 净利润 | 本期值 + 同比增长率；标归母/含少数 |
| 毛利率 | `(营业收入 − 营业成本) / 营业收入`；分子分母的原值都要留 |
| 净利润率 | `净利润 / 营业收入` |
| ROE | 标加权还是摊薄；净资产取期末数还是平均数也要写 |
| 经营利润率 | `营业利润 / 营业收入`；注意是**营业利润**，不是利润总额 |

### 3.2 成长性

三个增长率：收入增长率、盈利增长率、账面价值增长率，都按 YoY。

关键在**同口径**：A 股法定披露是累计口径，中报是上半年、三季报是前三季。拿累计当单季比会错得很离谱。单季值按 `data-standard.md` §2.2 换算：

- Q2 单季 = 中报 − 一季报
- Q3 单季 = 三季报 − 中报
- Q4 单季 = 年报 − 三季报
- Q1 单季 = 一季报本身

换算过程按「计算指标」格式留痕。

### 3.3 财务健康

| 指标 | 算式 | 口径注意 |
| --- | --- | --- |
| 流动比率 | 流动资产 / 流动负债 | 期末时点数 |
| 资产负债率 | 总负债 / 总资产 | 期末时点数 |
| D/E | 总负债 / 股东权益 | 标明股东权益是否含少数股东权益 |
| 经营性现金流 | 本期金额 | 期间发生数，标累计口径 |
| FCF | 经营性现金流 − 资本支出 | 资本支出 = 购建固定资产、无形资产和其他长期资产支付的现金 |

### 3.4 估值参考

**这组的数不在财报里。** 财报只提供分母（净利润、净资产、营业收入、EBITDA），收盘价得从行情源取（Wind / 同花顺 / 东方财富）。

| 指标 | 算式 | 要标什么 |
| --- | --- | --- |
| P/E | 总市值 / 净利润 | 分母是 TTM 还是最近一期年报 |
| P/B | 总市值 / 净资产 | 净资产取归母 |
| P/S | 总市值 / 营业收入 | 分母期间 |
| EV/EBITDA | (市值 + 有息负债 − 现金) / EBITDA | EBITDA 的算法 |

**来源标成「行情数据（来源：Wind/同花顺等，日期）」**，不要标成财报页码 —— 标错了下游会以为收盘价是从年报里读的。

拿不到行情数据 → 写「需外部行情数据」，**不要拿财报里的数硬凑一个收盘价**。估值建模本身交给 `valuation` 技能，这里只负责把原始输入摆齐。

## 四、数字格式

照 `data-standard.md` §三 抄，别自己发挥：

| 类型 | 格式 | 示例 |
| --- | --- | --- |
| 金额 | 亿元，2 位小数 | `1,234.56 亿元` |
| 比率 | 百分数，2 位小数 | `46.20%` |
| 比率变动 | 百分点，2 位小数 | `+2.35 pp` |
| 增速 | 百分数，2 位小数 | `+12.34%` |
| 倍数 | 2 位小数 | `18.75 倍` |
| 日期 | YYYY-MM-DD | `2026-09-12` |
| 报告期 | YYYY 年报 / YYYYQ1~Q4 | `2025 年三季报` |

另外两条：

- 内部计算用**原始值精确算**，只在展示时四舍五入。别拿四舍五入后的数再算下一层。
- 分母为负（亏损）时增速没有意义 → 不写百分数，改写成「由盈转亏」「亏损收窄 X 亿元」。

## 五、每个数字都要能倒查

财报原文里的数，除了算完的比率，**原始值也要留** —— 下游分析师要复算，没原值就得回原文翻一遍。

```
营业收入（累计口径）1,234.56 亿元（来源：2026 年半年报，第 11 页）
毛利率 46.20%（计算方式：（营业收入 − 营业成本）/ 营业收入，基于 2026 年半年报，第 12 页）
```

## 六、提不到的数怎么标

| 情况 | 怎么写 |
| --- | --- |
| 来源说不清是谁发的、什么时候发的 | `[待核实]` + 说明卡在哪 |
| 来源里有，但取决于版本/口径 | 写数值 + `[待核实：口径]` + 说清疑问点 |
| 来源里确实没有这项 | 「未披露」 |
| 该对比不适用（如新上市公司没有上年同期） | 「—」 |
| 需要估算 | `[估算]` + 方法与依据，**不与其他实测数字混在同一列** |

**四条禁止**：不编数、不用记忆里的数、不拿估算冒充实测、不因为「这里应该有个数」就补一个。

`[待核实]` 的项最后要**汇总成一节**，不能散在表格里被读者漏掉。

## 八、交棒

写完汇报四件事：**提了哪几组、各多少项、缺什么、有几条 `[待核实]`**，并说明文件落在哪。

然后**停下**。数据源确认是项目 `CLAUDE.md` 第五节的第 1 个「人在回路」节点，必须等分析师确认数据是否齐全、是否可靠，才轮到下游接棒。

## 必须遵守的规则

1. **不编数、不编页码、不编链接、不编来源**。说不清的一律标 `[待核实]`。
2. **只在 `raw_data/earnings/` 下写入**，不碰 `analysis/`、`output/` 和 `raw_data/` 的其他子目录。
3. **不主观判断**。两个来源的数字打架，活儿是把两边都记清楚，不是拍板哪个对。
4. **不跳过口径**。每个数字至少标期间 + 单位，利润类加标归属。没标口径的数等于没提。
5. **不越人在回路节点**。提完即停，等第 1 个节点确认。
