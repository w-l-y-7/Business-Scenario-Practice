# esg：环境、社会与治理

读 `raw_data/earnings/`（财报「公司治理」「董事会报告」「审计报告」「环境与社会责任」等章节）、`raw_data/filings/`（公司公告、ESG / 社会责任报告、监管处罚公示）与 `raw_data/news/`，产出 `analysis/esg.md`，对应 CFA 研报第 ⑦ 节 **Environmental, Social, and Governance**。

**这一节的目标不是给公司贴「ESG 良好」的标签，而是找出对股东和利益相关方不利的地方。** A 股常见的几个雷区：一股独大下的关联交易与资金占用、董事会形同虚设、大股东股权质押、审计意见非标、环保与安全生产处罚、H 股发行对 A 股股东的稀释。这些都要找出来。

**分析的落点是「钱和权怎么分配」。** 治理不是一堆委员会名单，它决定的是：谁说了算、管理层的利益和股东一致不一致、赚到的钱是留在公司、分给股东、还是流去了别处。**治理的每一块都要往这三件事上收。** 环境与社会两块则要落到**成本、产能、合规与客户关系**上，不写没有判据的「环境友好」这类评价。

## 研究范围

**官方评分表 Appendix D 里这一节占 15 分，用名是 `Environmental, Social, and Governance`，三块都要有实质内容。** 本技能做下面三大块，共 15 个模块：

### E —— 环境

| # | 模块 | 要什么 |
| --- | --- | --- |
| E1 | **环境合规与处罚** | 环保处罚记录（时间、事由、金额、是否整改）、排污许可、环评批复、生态环境部门监管公示 |
| E2 | **能耗与碳排放** | 用电量 / 能耗强度、温室气体排放（范围一 / 二 / 三）、是否纳入碳市场、绿电比例。**标清核算年份与组织边界**（母公司还是合并） |
| E3 | **环保投入与资本开支** | 环保设施投入（资本化还是费用化）、对应什么改造、占 CapEx 的比重 |
| E4 | **环境相关风险与约束** | 限产、配额、极端天气对生产基地的影响、供应链环境责任、客户（尤其海外大客户）的环保准入要求 |

### S —— 社会

| # | 模块 | 要什么 |
| --- | --- | --- |
| S1 | **安全生产与员工健康** | 安全事故（时间、等级、伤亡、处罚、是否停产）、安全生产许可证、职业病防治 |
| S2 | **员工结构与关键人员** | 员工总数与构成（生产 / 研发 / 销售）、研发人员占比与流失、核心技术人员稳定性、员工薪酬与社保合规 |
| S3 | **供应链责任** | 供应商集中度与合规、冲突矿产、劳工标准、有无因供应链问题被客户施压 |
| S4 | **产品与客户责任** | 产品质量与召回、数据与隐私合规（若适用）、出口管制与贸易合规对客户关系的影响 |

### G —— 治理（本技能的核心块）

| # | 模块 | 要什么 |
| --- | --- | --- |
| G1 | **控制权与股权结构** | 实际控制人及控制链条、第一大股东持股、一致行动人、股权质押、控制权稳定性、减持动向 |
| G2 | **董事会结构与独立性** | 董事人数与构成、独立董事占比、董事长与总经理是否兼任、专门委员会、近三年变动、独董是否真正履职 |
| G3 | **内部控制与审计** | 审计机构与意见类型、内控评价与内控审计意见、近三年是否更换审计师、关键审计事项（KAM） |
| G4 | **管理层激励** | 股权激励与员工持股方案、行权条件、限制性股票归属安排、高管薪酬与业绩挂钩程度、递延与追索条款 |
| G5 | **资本配置** | 分红政策与分红率、回购（注销还是用于激励）、再投资去向、募资用途变更 |
| G6 | **关联交易、资金占用与担保** | 关联交易占营收 / 采购比重、定价公允性、大股东非经营性资金占用、对外担保 |
| G7 | **股东稀释与中小股东保护** | **H 股发行对 A 股股东的稀释**、回购注销的增厚效果、摊薄后每股指标、类别股东表决安排、中小股东提案与表决权保护机制 |

> **G7 是本项目新增的重点。** 中际旭创 2026 年完成 H 股发行，股本从 A 股单独口径变为 A+H 合并口径。**这一块要写清稀释了多少、对每股价值的影响，并与 `model/` 的股数桥对齐** —— 同一组股数只在一处列全（模型），这里引用并分析治理含义。

## 一、动手前先定四件事

1. **报告期** —— 读哪份财报 / ESG 报告
2. **数据可得性** —— 董事会构成与审计意见在年报「公司治理」章节；股权质押、关联交易、分红方案在公告里；环保与安全数据在年报「环境与社会责任」章节、ESG 报告、监管公示里
3. **与 `business` 的分工** —— 见 §四
4. **与 `model/` 的分工** —— 股数、稀释、分红金额这些**模型输入**只在 `model/inputs/` 与 `model/results/` 里定义，本节引用不重算

## 二、E 与 S 怎么写（必做）

**E 与 S 是这一节的完整组成部分，不是「命中才写」的可选项。** 三块按官方评分表同级，篇幅不够时压缩的是描述性文字，不是整个块。

### 2.1 先查，再决定写多深

**每一块都要先查一遍**，查完按结果分四种情况写，**四种不许混**：

| 情况 | 怎么写 | 含义 |
| --- | --- | --- |
| **未检索**（not_searched） | `[未检索]` + 写明为什么没查（超出本轮范围 / 资源限制） | **我们的工作没做到** |
| **已检索未找到**（searched_not_found） | 「未检索到」+ **写明查了哪些来源** | 我们查了，没有这一项 |
| **未披露**（not_disclosed） | 「未披露（已查：A、B、C）」+ 写明查了哪些来源 | 公司没说 |
| **不适用**（not_applicable） | 「—」+ 一句理由 | 该指标对本公司不成立 |

**「已检索未找到」和「未披露」不能混用。** 前者是我们查完了没找到，后者是公司该说而没说 —— 后者本身就是一个 ESG 结论。反过来，把「没去查」写成「未披露」，等于把自己的缺口算到公司头上。

### 2.2 数据来源与定级

| 来源 | 等级 |
| --- | --- |
| 法定披露文件（年报「环境与社会责任」章节、监管处罚公示、排污许可、安全生产许可） | **A 或 B** |
| ESG / 社会责任报告，**经第三方独立鉴证**（如 ISAE 3000） | **B** |
| ESG / 社会责任报告，**未鉴证但指标同时出现在法定披露文件里** | 以法定那份为准，**A 或 B** |
| ESG / 社会责任报告，**未鉴证且纯自愿披露** | **C**（须有 A / B 级佐证才能进结论） |

**公司自己的 ESG 报告不因「ESG」二字一律降为 C 级** —— 按 `data-standard.md` §4.3 三条件判定。同一个数据点在 ESG 报告和年报里都出现、且数字打架时，**以年报为准**并在备注写清分歧。

### 2.3 E / S 的落点

**E / S 数据不单独下「环境友好」「社会责任良好」这类结论** —— 那是没有判据的评价。它们的用途有两个：

1. **汇入风险判断** —— 按 `risks` 技能的五要素写法进风险清单（环保限产影响产能、碳成本进入成本结构、事故导致停产、客户因合规问题转单）
2. **汇入估值假设** —— 环保资本开支改变 CapEx 节奏、碳成本进入毛利率、安全生产投入进入费用。**进了估值假设的部分要在 §五 写清影响路径与影响指标，并同步给 `financial-analyst`**

## 三、G 怎么写（本技能核心）

### 3.1 控制权与股权结构（G1）

- 第一大股东持股比例、前十大股东合计持股、**实际控制人及其完整控制链条**（层层穿透到自然人 / 国资 / 集体）
- **股权质押比例** —— 大股东高比例质押是明确的风险信号，要写进风险清单
- 一致行动人、有限合伙架构、表决权委托这类**控制权安排**
- **控制权稳不稳** —— 有没有争夺迹象、有没有在减持、有没有司法冻结
- **一股独大对中小股东的影响**：关联交易和资金占用要重点看（接到 G6）

### 3.2 董事会结构与独立性（G2）

- 董事会**总人数**、**独立董事人数与占比**（低于三分之一是明确的弱信号）
- **董事长与总经理是否由同一人担任** —— 兼任意味着决策权与执行权不分离
- 专门委员会（审计、薪酬、提名）是否设立，独立董事是否占多数
- 董事会**近三年变动频率** —— 频繁变动说明内部不稳定或控制权有争夺
- **独立董事有没有真正履职** —— 有没有投过反对票 / 弃权票、审计委员会开过几次会。只看「独董占比达标」不够，占比达标但从不投反对票，是形式上的独立

### 3.3 内部控制与审计（G3）

- **审计机构名称**、**审计意见类型**（标准无保留 / 带强调事项段 / 保留 / 无法表示意见 / 否定）
- **内控评价报告与内控审计意见** —— 很多公司财报审计是标准意见，但内控被出具否定意见，这个要单独说
- **近三年是否更换审计师**，更换要查明原因；年报里通常要披露
- **关键审计事项**（KAM）里点了什么 —— 那是审计师自己认为风险最高的地方
- 非标准审计意见 → **最高优先级的治理风险**，进风险清单的「高影响」档

### 3.4 管理层激励（G4）

- 有没有股权激励、员工持股计划；有的话写出**行权条件**（业绩门槛是什么、几年、几期）
- **尚在归属期内的限制性股票数量与归属时间表** —— 这是**股东稀释**的输入（接到 G7），要与 `model/` 的 vesting schedule 对齐
- 行权条件**过于宽松**（如只需收入增长不要求利润、或门槛低于行业自然增速）→ 点明这会激励规模扩张而非股东回报
- 高管薪酬总额与净利润的对比、是否有递延支付和追索扣回条款
- **激励对象是不是只覆盖高管** —— 核心技术团队有没有覆盖，直接关系到关键人员稳定性

### 3.5 资本配置（G5）

**这一块回答「公司赚的钱去哪了」，是治理分析里最接近估值的一节。**

| 看什么 | 怎么判断好坏 |
| --- | --- |
| **分红政策** | 分红率（股利 / 归母净利润）高低、连续几年分、有没有明确的分红承诺。**长期高盈利却常年低分红、且账上现金大量闲置 → 点明** |
| **回购** | 回购是注销还是用于激励；注销才真正增厚每股价值，用于激励只是换个形式的薪酬 |
| **再投资去向** | 留存收益投到了哪 —— 主业扩产、还是多元化 / 财务性投资。**跨界投资是要重点提示的信号** |
| **募资用途变更** | 募来的钱有没有改用途、改了多少、改去哪。频繁变更是负面信号。**H 股募集资金的实际用途要单独核**（接到 G7） |

### 3.6 关联交易、资金占用与担保（G6）

| 看什么 | 怎么判断 |
| --- | --- |
| **关联交易** | 占营收 / 采购的比重、定价是否公允、有没有逐年上升 |
| **资金占用** | 有没有大股东非经营性占用资金。**这是治理硬伤，直接进风险清单「高影响」档** |
| **对外担保** | 有没有为大股东或关联方担保、金额多大、有没有反担保 |

### 3.7 股东稀释与中小股东保护（G7）

**这一块是本项目新增的重点，直接关系到底每股价值，必须与模型对齐。**

| 看什么 | 要什么 |
| --- | --- |
| **H 股发行的稀释** | 发行股数、占发行后总股本的比例、募集资金净额、对每股收益与每股价值的摊薄 |
| **摊薄后口径** | basic / issued / potential awards / projected diluted 四种股数口径的差异（**数从 `model/` 来，这里只解释含义**） |
| **限制性股票归属** | 尚未归属数量、归属时间表、作废数量。**防止与 H 股新股重复计入股数** |
| **回购注销** | 注销式回购对每股价值的增厚 |
| **类别股东安排** | A / H 两类股东的表决权、分红权是否一致；H 股有无特殊条款 |
| **中小股东保护机制** | 累积投票制、网络投票、中小股东提案权、独立董事提名权、关联交易回避表决 |

**判断基准是「现有股东的每一股有没有被稀释掉价值」。** 发行价低于内在价值、募资投向回报率低于 Ke、限制性股票归属条件宽松，都会稀释现有股东 —— 无论募资本身多么「有利于长期发展」。

## 四、与 `business` 的分工（别写重）

两份报告都会涉及股权，但**视角不同**：

| | `business.md`（§2.5） | `esg.md`（§3.1） |
| --- | --- | --- |
| 视角 | **描述**：谁持股、持多少 | **分析**：这个结构对中小股东意味着什么 |
| 写什么 | 前十大股东名单、持股比例、实际控制人 | 股权集中度的治理影响、质押风险、关联交易倾向、控制权稳定性、稀释 |

**同一组数字只在一处写全，另一处引用。** 例如持股比例在 `business.md` 列全表，`esg.md` 引用并展开分析；股数与稀释数在 `model/` 里列全，两份报告都只引用。

## 四、分析正文

### 4.1 环境（E）

## 必须遵守的规则

1. **不编数**。取不到就按 §2.1 四种状态之一标注，**绝不填估算值，也不拿「行业普遍如此」搪塞**。
2. **只在 `analysis/esg.md` 写入**，不碰 `raw_data/`、`model/` 和 `output/`。
3. **E / S / G 三块都要写**。E 与 S 不是可选项 —— 查完没有就标「已检索未找到」并写明查了哪些来源，但**不能整块不写**。
4. **只从公开披露的事实下判断**。不做无根据的动机推测；「董事会形同虚设」这种话要有具体依据（如独董从未投反对票、专门委员会未召开过会议）。
5. **审计意见是最高优先级信号**。非标准意见要放在结论摘要里，不能埋在小节里。
6. **与 `business` 不写重**。同一组数字一处列全、另一处引用。
7. **股数与稀释数只从 `model/` 来**，本节不自己算股数、不算摊薄比例。
8. **E / S 数据不单独下评价**，只服务于风险判断与估值假设，并写明影响路径。
9. **硬伤同步给 `risk-analyst`**，进假设的同步给 `financial-analyst`，但**不在这里建风险情景** —— 情景要落到模型假设上，由统一模型算。
10. **不越人在回路节点**。
