# financial：财务分析

只读 `raw_data/earnings/` 下的财报指标文件，从**财务视角**评估公司质量，产出 `analysis/financial.md`。

**这是分析，不是采集。** 你的活儿是在数据的基础上**下判断** —— 盈利能力强不强、增长是不是真的、债务扛不扛得住。但每个判断都要能指回具体指标和阈值，不能凭印象说「感觉还不错」。

**不碰估值。** DCF、FCFE、可比公司、目标价区间、估值倍数快筛，全部归 `valuation` 技能。这里只回答「经营和财务质量怎么样」，不回答「贵不贵」。

**历史指标要喂给统一模型。** 本技能算出来的比率与增速（毛利率、周转天数、增长率等）是 `model/inputs/historical.yaml` 的内容 —— **口径必须标死**，模型按这个口径往前推。口径含糊的输入，模型算得再对也是错的。**这里不预设任何未来假设**，预测归 `valuation` 的候选假设表。

**经营质量不等于股票评级。** 这里的三路信号是**对经营与财务事实的分类**，不是买 / 持 / 卖的建议。一家公司财务再漂亮，价格透支了也不该买；财务平平但价格足够低，也可能值得买。**评级只在 `valuation` 技能里、结合价格形成**，本技能的任何输出都不得直接当作评级使用。写结论时也不给「看多 / 看空」以外的方向性暗示 —— 「看多」指的是经营质量好，不是股价会涨。

**不给精确到小数点的「信心度」。** 三个子分析里两个看多一个中性，本来就只是「多数子分析偏正面」这么一件粗事，把它换算成 `66.67%` 这种数会凭空多出两位有效数字，读者会当成「有 66.67% 的把握」。**一致程度用定性描述**（一致 / 基本一致 / 有分歧 / 方向相反），可靠的数字只留下面那个可计算、可解释的**数据完整度**。

> 本技能原名 `fundamental`，2026-09-18 按 CFA 研报结构改名。原第四路子分析「估值合理性（倍数快筛）」已移交 `valuation` 技能，本技能由四路降为三路。

## 速查表

| 子分析 | 看什么 | 信号规则（按有效指标达标率） |
| --- | --- | --- |
| 盈利能力 | ROE、净利润率、经营利润率 | 达标率 ≥ 2/3 → 看多；= 0 → 看空；其余 → 中性 |
| 成长性 | 收入、盈利、账面价值三个增长率 | 同上 |
| 财务健康 | 流动比率、D/E、FCF/净利润 | 同上 |

指标缺失 → **不计入分母**，另算「数据完整度」。全部缺失 → 该子分析标「无法评估」，不产信号。

## 一、动手前先定三件事

1. **标的与报告期** —— 读哪份财报文件
2. **行业** —— 这决定阈值能不能直接用（见 §三）
3. **数据完整度** —— 先通读 `raw_data/earnings/` 那份文件，看哪些指标拿得到、哪些是 `[待核实]` 或「未披露」

**先数一下有多少项能用。** 如果拿到的东西本来就少，那这份报告的主要结论可能是「数据不足以判断」，而不是「财务质量差」—— 这两者天差地别，别搞混。

## 二、三个子分析

三个子分析**并行独立**执行，各自产出一个信号。互不干扰 —— 盈利能力看多、财务健康看空是完全可以的，不要为了凑一个统一叙事去调和它们。

### 2.1 盈利能力

| 指标 | 通用阈值 | 达标含义 |
| --- | --- | --- |
| ROE | ≥ 15% | 股东回报健康 |
| 净利润率 | ≥ 20% | 利润水平充足 |
| 经营利润率 | ≥ 15% | 运营效率良好 |

### 2.2 成长性

| 指标 | 通用阈值 | 达标含义 |
| --- | --- | --- |
| 收入增长率 | ≥ 10% | 收入有意义扩张 |
| 盈利增长率 | ≥ 10% | 盈利跟上收入 |
| 账面价值增长率 | ≥ 10% | 内在价值在积累 |

成长性看的是**同口径的同比**。拿累计比单季、拿归母比含少数，算出来的增速没意义。口径不清的先回 `raw_data/earnings/` 确认，确认不了就标 `[待核实]` 并当无效指标处理。

### 2.3 财务健康

| 指标 | 通用阈值 | 达标含义 |
| --- | --- | --- |
| 流动比率 | ≥ 1.5 | 短期流动性充足 |
| D/E | ≤ 0.5 | 负债水平保守 |
| FCF / 净利润 | ≥ 0.8 | 盈利有现金流支撑 |

**FCF / 净利润 这条要留神**：净利润为负时这个比值没有意义，分母为负的比值一律作废（照 `data-standard.md` §三），该指标当无效处理，不判达标也不判不达标。

## 三、行业校准（这一步不能跳）

上面那套阈值是**跨行业通用值**。直接套到 A 股会出问题：不同行业的净利率、负债率差好几个量级。ICT 硬件、系统集成、商贸这类行业的净利率普遍是个位数，拿「净利润率 ≥ 20%」去卡，必然全判看空 —— 那不是公司差，是尺子错了。

所以：

1. **先定行业**（公司主营业务落在哪个口径，参照 `raw_data/reports/` 里券商研报的行业归类）
2. 通用阈值当默认
3. 阈值明显不适用时调整，**调整必须写明依据**
4. 依据要能指回去：
   - 券商研报里的行业数据 → 标 `（来源：中金，《XX 行业深度》，2026-08-15，B 级）`
   - 没有来源、只能靠常识判断的 → 标 `[估算]` 并声明「依行业常识判断，无来源支撑」
5. **没写依据的调整一律算编数**。宁可保留通用阈值、在报告里说明局限，也不要悄悄改一个数让结果好看。

调整过的阈值要在报告里**单列一张表**：

| 指标 | 通用阈值 | 本行业采用值 | 调整依据 |
| --- | --- | --- | --- |

**这张表就是「人在回路」第 2 个节点（核心假设审查）的核心内容** —— 阈值是关键假设，改了什么、为什么改，必须让分析师过目。列完先停，等确认。

## 四、评分与信号汇总

### 4.1 单个子分析的信号

对每个子分析：

```
有效指标数 = 拿到的、且口径明确的指标数
达标数     = 达标的指标数
```

- **有效指标数 = 0** → 该子分析标「**无法评估**」，**不产信号**，不进分母
- **有效指标数 ≥ 1** → 按**达标率**判定：

| 达标率 | 信号 |
| --- | --- |
| ≥ 2/3 | 看多 |
| = 0 | 看空 |
| 其余 | 中性 |

用达标率而不是固定分数，是为了**指标拿不全时规则仍然成立**。三项全拿到时它跟「得分 ≥ 2」的原始规则完全一致；只拿到一两项时也不会因为分母写死 3 而永远够不到门槛。

有效指标数 = 1 时信号照给，但该子分析下要注明「**仅 1 项指标有效，信号可靠性低**」。

### 4.2 整体信号

只看**有效子分析**（排除「无法评估」的）：

- 看多数 > 看空数 → **整体看多**
- 看空数 > 看多数 → **整体看空**
- 相等 → **中性**
- 有效子分析数 = 0 → **整体无法评估**

### 4.3 一致程度（定性，不给百分比）

只看**有效子分析**，用三档词描述三路信号之间的关系：

| 情况 | 怎么写 |
| --- | --- |
| 三路同向 | **一致**（全部看多 / 全部看空） |
| 多数同向、另一路中性 | **基本一致** |
| 既有看多又有看空 | **有分歧** |
| 看多与看空数量相等 | **方向相反** |

**不给精确到小数点的百分比。** 「两个看多一个中性」换算成 66.67%，是给一件粗事硬加了两位有效数字，读者会读成「有 66.67% 的把握」。一致程度只描述**子分析之间同不同向**，跟「结论有多对」无关 —— 三路一致也可能全错（三个指标都取了错口径）。该不该信这个结论，看的是每个子分析里**证据硬不硬、口径清不清**，写在各自的依据里，不是算出来的一个数。

### 4.4 数据完整度

这个数可以算，单独给，别跟一致程度混：

```
数据完整度 = 有效指标数 / 9 × 100%     （3 个子分析 × 3 项指标）
```

**数据完整度低于 50% 时，结论摘要里必须明写「本报告基于不足半数指标，结论仅供参考」。** 它衡量的是「指标取到了多少」，**不是「结论多可靠」** —— 9 项全取到，也可能是 9 项全取了错口径或错期间。

## 六、交棒

写完汇报：**整体信号、一致程度、数据完整度、有几个子分析「无法评估」、阈值有没有调整**，并说明文件落在哪。

然后**停下**，等两个「人在回路」节点：

1. **核心假设审查（第 2 个节点）** —— 也就是 §三 那张阈值调整表，必须经分析师确认
2. **分析逻辑审查（第 3 个节点）** —— 因果关系是否成立、结论有没有过度外推

**不越过节点自动往下走。**

## 必须遵守的规则

1. **不编数**。阈值调整必须有依据，没依据就保留通用阈值并声明局限。
2. **只在 `analysis/financial.md` 写入**，不碰 `raw_data/`（那是采集的地盘）和 `output/`（那是 report-writer 的地盘）。
3. **缺失不等于不达标**。「没查到」和「不达标」是两个信号，混为一谈会把数据缺口误报成经营恶化。缺失项不计入分母，另外用数据完整度体现。**`[未检索]`（本轮没查）和「未披露」（公司没说）也要分清** —— 把「没去查」写成「未披露」，等于把自己的缺口算到公司头上。
4. **不越界做估值**。倍数快筛、DCF、FCFE、可比公司、目标价全归 `valuation`，这里一概不碰。
5. **不调和矛盾**。三个子分析信号打架是正常且有信息量的，照实报，别硬凑一个前后一致的叙事。
6. **不越人在回路节点**。阈值调整和分析逻辑都要等确认。
7. **经营质量不是股票评级**。本技能的三路信号不构成 BUY / HOLD / SELL —— 评级由 `valuation` 结合价格形成。也不给精确「信心度」百分比，一致程度用定性词（一致 / 基本一致 / 有分歧 / 方向相反）。
8. **来源等级不等于结论可靠**。指标取自 A 级财报原文，只说明数字从哪来；口径选错、期间混淆，结论照样错。每个子分析要交代关键指标的口径。
