# 日报 / 周报复盘规则

生成日报或周报时，在标准报告内容之后，必须追加一段"复盘"章节（日报叫"今日复盘"，周报叫"本周复盘"）。

## 适用场景

| 报告 | 什么时候生成 | 复盘章节 |
|------|------|------|
| 日报 `reports/{YYYY-MM-DD}-日报.md` | 需要日报时（手动触发，不再每天自动出） | 今日复盘 |
| 周报 `reports/{YYYY-MM-DD}-周报.md` | 每周日（weekly-routine loop 触发） | 本周复盘 |

## 复盘内容

基于对应时间范围（当天 / 本周）的 changelog.md 实际处理记录，回答三个问题：

1. 效率回顾：这段时间的任务处理是否顺利？有没有路由错误、处理失败或反复修改的情况？
2. 经验沉淀：发现了什么值得记住的模式、技巧或注意事项？
3. 改进建议：流程、模板、skill 有没有需要优化的地方？

## 约束

1. 复盘必须基于事实（changelog 记录），不凭空编造
2. 如果发现可复用的经验，建议保存到 memory
3. 如果发现 skill 或规则需要调整，主动提醒用户
4. 对应时段无任务处理时，日报复盘写"今日无任务处理"，周报复盘写"本周无任务处理"
